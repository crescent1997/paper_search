# paper_search

論文の探索・整理・要約を目的とした個人用リポジトリです。

## 注意事項

このリポジトリに含まれる論文要約・メタデータ・分類・リンク情報の一部は、LLM（Large Language Model）を用いて作成・編集されています。

可能な範囲で原論文、arXiv、公式proceedings、著者が公開した公式コードなどの一次情報を確認していますが、LLMによる生成・編集の性質上、以下のような誤りが含まれる可能性があります。

- 著者名・所属・採択先などのメタデータの誤記
- 論文内容・実験結果・手法の解釈違い
- 引用数や公開状況など、時点依存情報の不一致
- 公式ではないGitHub repositoryや関連リンクの誤認
- 要約時の情報欠落や過度な単純化

特に、研究上重要な判断や正確な引用に利用する場合は、必ず原論文および公式情報を確認してください。

誤りを発見した場合は、確認できた一次情報に基づいて随時修正します。
