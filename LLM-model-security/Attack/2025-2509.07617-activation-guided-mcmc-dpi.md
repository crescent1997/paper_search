# Transferable Direct Prompt Injection via Activation-Guided MCMC Sampling

## 概要

**target modelのgradientを使うGCG型攻撃を、activation-guided surrogate scoreによる転移型direct prompt injection (DPI)に置き換える**研究。攻撃が対象とするのは、アプリケーション側のhigher-priorityなprimary instructionと、それに反するattacker-controlled user inputの衝突である。modelのInstruction Hierarchyを直接学習・改善する研究ではないが、GCG-Injectを明示的に比較しており、hierarchy defenseのblack-box stress testへ発展可能な技術的祖先としてAttackに収録する。
