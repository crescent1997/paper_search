# 概要
動画の時間方向とTransformer内部の冗長性を別々に削減する。フレーム選択で入力を短縮し、prefill後にvisual KVを圧縮する。追加学習不要。

## 問題設定・先行研究との差
一律の予算配分では層ごとの視覚情報の需要を反映できない。またtoken削除は対応するvalue情報を失う。Q-Frameのような入力選択とPyramidKV等の層別圧縮を組み合わせる方向だが、Keyを削除しつつValue情報を融合する点が特徴。

## 手法
公式実装READMEに基づく処理順序:
1. CLIPの画像・命令特徴から関連性と多様性を考慮してフレームを絞る。
2. 選択フレームをVLMでprefillし、各層のattentionからtoken重要度を集約。
3. 視覚placeholderの位置を特定し、重要度上位のvisual tokenを選択。非視覚tokenは保持する。
4. 層が深くなるほど保持数を放物線状に減らし、指定した層以降はvisual KVを除外する。削除対象のValue成分を残存token側に融合する。
5. 圧縮したpast_key_valuesを生成に渡す。

公式実装の初期設定ではフレーム保持率0.5、global visual token保持率0.67、層の打切り位置は全層の約75%。融合係数0.2。これらは公開コードのデフォルトであり論文の全実験に共通とは限らない。

## Experiment Setup
公式実装が列挙する評価モデル: Qwen2.5-VL 3B/32B、Qwen3-VL 4B、LLaVA-OneVision 7B。評価データはMVBench、EgoSchema、DREAM-1K、ActivityNet-QA、NExT-QA、ActivityNet Captions。比較対象はQ-Frame、PyramidKV、FastV、PyramidDrop。公開評価コードにはCUDA eventによる時間測定、KV容量、理論decode FLOPsの集計がある。GPU機種、生成長、各比較条件は本文未取得につき不明。

## Main Results
公式abstractでは最大2.35倍の高速化とKV保持率19–28%で競争力のある精度を報告。保持率から算出したKV削減率は72–81%。最大高速化と最低保持率が同じ実験条件とは限らない。各データセットの正確な精度、TTFT、TPOT、実測VRAM、throughputは未確認。

フレーム選択、層別予算、Value融合の個別寄与を比較することが重要だが、原論文のablation表は未取得。定量値は記載しない。

## Limitations
以下は手法・公開実装からの考察。重要フレームが早期に欠落すると後段の融合では回復できない。attention集計のためのprefillと圧縮処理には追加費用が発生する。層別の異なるcache長やposition/mask管理は推論エンジンへの統合時に検証が必要。KV容量削減とGPU全体の使用量削減は別指標。VLAでの成功率・制御周波数は評価対象外であり、ロボットへの適用効果は未検証。

## taxonomy
visual KV cache compression / token eviction / value fusion。過去フレームのTransformer KV tensorを再利用する方式ではない。入力側のフレーム選択はprefill短縮にも寄与し、prefill後の圧縮は主にdecode側に作用する。
