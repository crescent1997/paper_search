# NativeMEM — Native Memory Compression

## 概要・問題設定
長時間のロボット操作では観測履歴の視覚tokenが増え、VLA推論のコストが高くなる。NativeMEMは履歴をactionに必要な情報へ圧縮する。

## 手法と先行研究との差
VLA自身のvision encoderを使い、action prediction lossで学習するmemory tokenizerによって過去の各frame-viewを1 tokenに変換する。記憶表現の学習後、タスク向けにVLAをfine-tuningする。KV cacheの直接再利用ではなく、履歴visual tokenの学習圧縮である。

## Experiment Setup / Main Results
シミュレーションの平均成功率84.0%（比較対象Mem-0は32.4%）、実機平均98.7%を報告。約200フレームの履歴を100ms以内で処理し、32GBのGPUメモリ予算で最大約5,000フレームの履歴を保持できるとする。比較条件や評価指標の詳細は原論文を参照。

## Ablation / Limitations
記憶表現の学習とVLAの追加fine-tuningが必要。推論コストは低いが、KV cache再利用やKV evictionを直接最適化する手法ではない。長期履歴の情報損失とaction成功率の関係が重要となる。
