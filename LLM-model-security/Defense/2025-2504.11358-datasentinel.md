# DataSentinel: A Game-Theoretic Detection of Prompt Injection Attacks

## 概要

**検出器を『低信頼データ中の命令を見つけるために、あえてその命令に反応しやすく学習させる』**という逆転の発想が特徴。GCGの離散最適化を防御側のadversarial trainingのinner-loopに組み込み、固定attackだけでなくdetector-awareな攻撃に備える。IEEE S&P 2025公式採択によりvenue fallbackを満たす。

本論文は**backend LLM自身がsystem > user > toolを遵守するように学習するDefenseではない**。独立したLLM detectorがuntrusted inputをスクリーニングするmodel-based guardであるため、StruQ / SecAlign / IH-Challengeとは区別して収録する。InstructDetector、PIShield、AlignSentinelなどとの比較対象。
