# ShadowKV: KV Cache in Shadows for High-Throughput Long-Context LLM Inference

## 問題設定
Long-context inferenceではGPU memory容量だけでなく、decodeで過去KVを読み出すmemory bandwidthが制約となる。単純なCPU offloadではPCIe転送がボトルネックになりやすい。ShadowKVはGPU上の小さな表現から重要tokenを予測し、必要なKVのみを取り出す。

## 手法
Keyの低rank性を利用して、選択に必要な小型の近似表現をGPU側に保持する。Valueなど大容量の情報はCPU側を含む階層memoryに配置する。Queryに対する近似attention scoreから重要な位置を推定し、必要なKVを集めてsparse attentionを実行する。実装ではmemory layout、非同期転送、batched retrievalを組み合わせることが重要。

## Experiment Setup・Main Results
Long-context QA・retrieval・generationの品質をfull attentionと比較し、GPU memory消費、CPU-GPU転送量、decode throughput、batch size scalingを測定する。speedupの評価ではPCIe bandwidth、sequence length、retrieval budget、batch sizeを明示すべきであり、kernel単体の速度とend-to-end serving速度を分ける。

## Ablation
低rank次元、sparse token budget、GPU resident metadata量、CPU-GPU転送のoverlap、selection精度の寄与を確認する。近似scoreが重要tokenを落とす場合、下流の回答品質に影響する。

## Limitations
CPU offloadingの効果はハードウェア構成に依存する。非連続なKV gatherはGPU kernel効率を損なう場合がある。長距離依存が分散したtaskではTopK選択が難しい。
