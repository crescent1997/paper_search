# EventVLA — 予測的なイベント記憶書き込み

## 概要

本論文の中心課題は、**ロボットが今見えないものを過去の一瞬の観測から思い出せるか**である。単なる長時間履歴の入力ではなく、途中で一度だけ見えた物体の色、蓋の中身、ボタン押下回数、ランダムに示された順番などの *transient evidence* を保持する。初期フレームと短期履歴からなるVisual Anchors（VA）に、将来のaction chunk内で記録すべき時刻を予測するKeyframe Evidence Memory（KEM）を加える。全履歴を保持するのではなくイベントの原画像を最大5枚保持する。**TransformerのKV cacheを再利用する方法ではなく、画像を選択して後続のVLM入力へ再投入する外部記憶方式**である。

## 問題設定・先行研究との差

観測 $o_t$ と指示 $l$ のみを入力する反応型policy $a_t=\pi(o_t,l)$ では、非Markovな操作に必要な過去の証拠が失われる。MemoryVLAなどの圧縮記憶は詳細な視覚情報を潰しやすく、dual-system型は高水準推論による遅延を増やし、全frame bufferは冗長性で計算が増える。EventVLAは「初期配置」「直近の動作」と「途中で消える決定的イベント」を分離し、未来に必要になる可能性を行動予測から判断する。RMBenchでは静的VAだけで高成功率になるため、新しいRoboTwin-MeMで本当に途中の記憶が必要かを診断する点も貢献。

## 手法

記憶 $M_t=A_t\cup E_t$ とし、$A_t$ は初期画像 $o_0$ と短期画像、$E_t$ は選択されたイベント画像を保持する。入力は時間順に $[A_t,E_{t-1},o_t]$ を連結する。KEMはaction horizon $H$ に沿った最終層hidden states $h_t\in\mathbb{R}^{H\times d}$ を受け、

$$\hat{\mathbf p}_t=\sigma(\mathrm{MLP}_{KEM}(h_t))\in[0,1]^H$$

として将来の各stepのkeyframe確率を推定する。閾値 $\tau_{commit}=0.55$ を超える候補を1D non-maximum suppression（radius 8）とcooldown（10 steps）で間引き、実際にその時刻が来たら画像を記録する。イベントbufferは $N_{max}=5$ でFIFO eviction。損失は $L=L_{action}+\lambda L_{kem}$（$\lambda=0.1$）。Keyframe正解時刻はQwen3-VLを用いたオフライン自動アノテーションで取得し、raised-cosine soft labelsを使ったBCEで学習。教師の正解記憶とモデル予測記憶の使用比率を1→0にannealする。**VLM backboneを含む追加学習が必要**で、training-freeではない。

## Experiment Setup

- シミュレーション: RMBench 9タスクと、新規RoboTwin-MeM 8タスク（1 episode平均430〜1,544 steps、必要な中間keyframe 1〜5）。標準Markov環境RoboTwin2.0も評価。
- シミュレーション基盤: QwenOFT / Qwen3-VL-4B-Instruct、画像224×224、action horizon 50、80,000 stepsのend-to-end学習。RMBenchではVAのみ、RoboTwin-MeMではVA+KEM。
- 実機: ARX ACONE双腕ロボット、4種類の非Markov操作、各20試行。実機用backboneは $\pi_{0.5}$ / PaliGemma、action次元32、60,000 steps学習。
- Baseline: $\pi_{0.5}$、QwenOFT、MemER、Mem-0、MemoryVLA（OpenVLA/QwenOFT）、$\pi_{MEM}$ など。GPU機種・GPUメモリ容量の実測は主要実験表で未報告。推論latencyはAppendix Table 9で報告。

## Main Results

| ベンチマーク / 比較 | Baseline | EventVLA | 評価上の注意 |
|---|---:|---:|---|
| RMBench平均 | MemoryVLA(QwenOFT) 41.7% | **67.8%** | EventVLAはVA-only、KEMなし |
| RoboTwin-MeM平均 | MemoryVLA(QwenOFT) 10.8% | **75.2%** | VA+KEM、最重要の比較 |
| RoboTwin-MeM平均 | VA-only 18.0% | **75.2%** | KEMによる差 +57.2pp |
| RoboTwin2.0 Easy | QwenOFT 80.0% | 83.8% | Markov環境 |
| RoboTwin2.0 Hard | QwenOFT 78.0% | 81.6% | Markov環境 |
| 実機 Find Block Easy/Hard | $\pi_{MEM}$ と比較 | 90% / 60% | 各20試行 |
| 実機 Pick-X-Times / Pick in Order | $\pi_{MEM}$ 30% / 40% | 90% / 75% | 長期のカウントと順序記憶 |

**推論効率の重要な負の結果**（Appendix Table 9、RoboTwin-MeM平均）:

| モデル | Latency (秒/chunk) | Throughput (chunk/s) |
|---|---:|---:|
| QwenOFT | 0.36 | 2.91 |
| EventVLA VA-only | 0.96 | 1.07 |
| EventVLA VA+KEM | **1.09** | **0.94** |

VA+KEMはQwenOFTに対して**約3.0倍のchunk生成時間**を要する。論文は低レベル制御と組み合わせれば実用範囲と解釈するが、制御周期そのものやend-to-endのtask wall-clockは別指標。**記憶精度改善を推論高速化と誤認してはいけない。** GPU memoryは未報告。

## 主要ablation

| RoboTwin-MeM構成 | 成功率 |
|---|---:|
| VA+KEM full | **75.2%** |
| VA-only | 18.0% |
| explicit画像ではなくlatent memory bank | 24.9% |
| hard keyframe labels | 48.8% |
| NMSなし | 53.4% |
| 最大event bufferを2に制限 | 32.0% |
| action chunkを50→30 | 31.1% |
| action chunkを50→15 | 13.6% |

RMBenchでは初期frameを除くと67.8→33.7%、短期履歴を除くと67.8→23.8%。**保存形式・書き込み判断・容量・予測horizon**が独立に重要である。KEMを使わず固定画像だけを保持する場合と、途中で消える証拠を捕まえる場合は異なる問題である。

## Limitations / 注意点

1. 最大5イベントのFIFOであり、10分超の高密度イベントで古い重要証拠が追い出される可能性。importance-aware eviction、圧縮、階層記憶は未実装。
2. 保存した生画像を再encodeするためVLM prefillとKV cacheのコストは増える。**連続frame間のvisual KV再利用やcache圧縮ではない**。KV再利用との組合せは未検証。
3. KEMの自動ラベル生成には大型VLM（Qwen3-VL-235B）のオフライン処理が必要。追加学習なしでは導入できない。
4. latencyは実測されるが、GPU memory、長時間実行中のbuffer使用量の時系列、完全な制御周波数の実測はない。実機の試行数は各20。
5. Venueは著者公式GitHubでCoRL 2026採択と記載、学会公式proceedingsとの照合は未完了。

## Taxonomy / KV cache研究への位置づけ

- **VLA / long-horizon memory / event-triggered write / bounded image buffer**。
- KV tensorのreuse・compression・evictionではなく、**外部画像記憶の選択・FIFO eviction**。MemoryVLAのlatent consolidationとは対照的にraw frame fidelityを優先する。
- 研究課題: 選択したevent frameのvisual encoder/KVを再利用すること、frame選択とKV memory budgetの共同最適化、FIFOの価値ベース置換。
