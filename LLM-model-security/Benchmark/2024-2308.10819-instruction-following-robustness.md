# Evaluating the Instruction-Following Robustness of Large Language Models to Prompt Injection

## 概要

[Instruction Hierarchy](../Defense/2024-2404.13208-instruction-hierarchy.md)や[StruQ](../Defense/2024-2402.06363-struq.md)以前の重要な評価設計。**「元のユーザー質問」と「検索文脈中に埋め込まれた別の質問」のどちらをモデルが解くか**を直接計測する。単に出力の有害性や拒否率を測るのではなく、priority conflictへの従属を測るため、後続のsystem/user/tool階層benchmarkとの技術的系譜を理解するのに適する。
