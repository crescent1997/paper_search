# 概要と問題設定
ECHO (Experience Consolidation and Hierarchical Organization)は、ロボットの長期操作経験をフラットなベクトルDBや単純な時系列履歴でなく、タスク→サブゴール→行動primitiveの**連続階層空間**に保存・検索するVLA外部記憶。対象は長期タスクの経験再利用と未経験の複合タスクへの一般化であり、Transformer layerのKV cache圧縮ではない。

# 先行研究との差
単純な短期bufferは直近情報を残すが長期の再利用が難しく、flat Euclidean kNNは意味的に似ていても実行上不適切な経験を引き当て得る。ECHOはLorentz双曲空間とentailment conesで親子・包含関係を表現し、階層探索で関連経験に絞る。MemoryVLAとの比較は同一pipelineでの再現値を含むが、学習条件が完全に同じとは限らない。[MemoryWAM](2026-2606.20562-memorywam.md)のようなvideo-side KV evictionとは機構が異なる。

# 手法
## 双曲Autoencoderと木構造
VLA hidden stateをHyperbolic AutoencoderでLorentz manifoldに写像。損失はreconstruction、親子距離、entailment cone違反ペナルティから構成される。グローバル指示を親、subgoal transitionを子とみなし、人手のskill tree注釈なしに成功軌跡からメモリを構築。メモリは双曲埋め込み、global instruction、subgoal説明、action segmentを保持する。

## Consolidationと検索
実行中は未整理bufferへ追加し、idle時に背景処理で階層木を更新。entailment coneに合わない新経験は新branch、内部不整合が大きいnodeはLorentz K-Means（K=2）でsplit。重複の整理・抽象化も行う。関連する2記憶の測地線補間で一時的なvirtual memoryを生成可能だが、実行成功の検証なしに恒久メモリへ追加しない。

検索はentailment条件付きtop-down beam search（beam幅3）で、全メモリへの一括kNNを避ける。検索したmemoryをtangent spaceに戻し、8-head cross-attentionで現在状態と整列。短期bufferと検索長期記憶をgateで融合し、元のπ0 action pathwayにsimilarity-modulated residualとして弱く注入する（base強度0.03）。

## 追加学習と運用コスト
HAE・gating・memory alignmentの学習が必要。さらにsubgoal抽出・成功判定用Qwen2-VL-7B-Instructをfine-tuneしており、記憶bankの品質はこの前処理に依存する。オンラインpolicy inferenceとは別に、経験検証・consolidation・検索のコストが存在する。実験ではmemory-bank preloadを含む前処理に約4.1–4.6分/実行。これを単一policy callのlatencyと混同しない。

# Experiment Setup
LIBERO Spatial/Object/Goal/Long-10とLIBERO-Plusを評価。π0を共通backboneとし、MemoryVLAをローカルpipelineで比較、Octo/OpenVLA/MAP-VLAは原論文値を参照するため完全な同条件比較ではない。cross-suiteではSpatial/Object/Goalの成功経験のみからbankを構築し、Long target-suite経験は使用しない。実機Franka Panda、3タスク×20試行、目標control loop約15Hz。評価GPUはRTX 6000 Ada×8、retrieval benchmarkはCPUで測定。

# Main Results
| 手法 | LIBERO-Long success | LIBERO-Plus success |
|---|---:|---:|
| Vanilla π0 | 80.7% | 54.2% |
| MemoryVLA（論文内再現） | 92.4% | 未測定 |
| **ECHO** | **93.5%** | **56.5%** |

LIBERO-Longではπ0に対して+12.8 percentage points、MemoryVLA再現値に対して+1.1 points。差の統計的有意性は別途検証が必要。cross-suiteの未見長期タスク構成では80.70→89.31%。実機3タスク平均は58.3→70.0%。成功率の改善は同じ実験条件内で比較すること。end-to-end policy latency・GPU VRAM・throughputの統一数値は論文の主表にないため、未確認とする。AppendixのCPU retrieval latency曲線は検索単体の性能。

# 主要Ablation（LIBERO-Long）
| 構成 | 成功率 |
|---|---:|
| Vanilla π0 | 80.70% |
| 短期bufferのみ | 88.81% |
| Flat Euclidean kNN memory | 83.25% |
| Hyperbolic distance kNN | 91.11% |
| Cone Tree Retrieval | 92.04% |
| **ECHO（consolidation込み）** | **93.48%** |

短期bufferだけでも+8.11pt、双曲距離kNNでさらに改善。階層探索・consolidationは追加改善をもたらすが、各差は数pt程度で、実験分散を考慮する必要がある。Flat memoryが短期bufferのみより低いことは、不適切な経験検索が有害となる可能性を示す。

# Limitations
成功経験を事前に収集し、VLMでtransitionを検証するためデータ収集・前処理負荷が大きい。異なるタスク・環境でのmemory tree肥大化、検索失敗、VLM判定誤りの蓄積は課題。オンライン推論のend-to-end latencyやGPU memoryの比較が不足し、実機は3タスクと小規模。双曲空間の効果は本論文のbackbone/設定内の結果であり、[MEM](2026-2603.03596-mem.md)に対する一般的優越を意味しない。

# Taxonomy・関連研究
- `vla / long-term episodic-semantic external memory / retrieval + consolidation`。**Transformer KV tensorのreuse/compressではない**。
- [MemoryVLA](2025-2508.19236-memoryvla.md): perceptual-cognitive memory。ECHOは経験の階層構造と検索・統合に注力。
- [MEM](2026-2603.03596-mem.md): multi-scale embodied memory。比較条件の相違に留意。
- [MemoryWAM](2026-2606.20562-memorywam.md): video DiT内部KVのgist圧縮であり、本論文とは別の記憶階層。
- [ReMEmbR](2024-2409.13682-remembr.md): captionと時空間情報の外部検索。ECHOは行動priorの階層検索。
