# 概要と問題設定
MemoryWAMは、長期観測履歴を要する非Markovロボット操作において、全履歴Transformer KV cacheのコストと短期windowによる忘却のトレードオフを解消するWorld Action Model (WAM)。学習時に動画予測とaction predictionを併用するが、推論時には動画生成を行わず、観測動画latentのKV更新とaction DiTのdenoisingだけを行う。論文の評価対象は単なる短時間のLIBERO操作でなく、履歴を失うと解けないRMBenchである。

# 先行研究との差
π0.5は現時刻の観測から行動を直接生成し、FastWAMなど効率重視WAMは短い観測windowに限定する。一方、LingBot-VAなど全履歴を保持するWAMは長期依存を処理できるが、履歴長に比例してKVメモリとattentionが増える。本論文は**Transformer内部の動画側KVを実際に保持・圧縮・evictする**ため、外部検索DB型MemoryVLAや[ECHO](2026-2605.10993-echo.md)とは異なる。

# 手法
## MoTと推論
事前学習済みWan2.2-TI2V-5Bのvideo DiTと別の1B action DiTをMixture-of-Transformersとして組み合わせる（総約6B）。観測画像はcausal video VAEで圧縮。各policy callでvideo DiTを1回通して現在のvideo KVを生成し、action DiTがそのKVにattentionしながら16-step action chunkを生成する。動画生成は学習時のみの補助教師信号。

## Hybrid memory
保持するvideo KVは、(1)直近4フレームの完全visual tokens、(2)タスク開始時2フレームのanchor完全tokens、(3)古いフレームごとの8個のgist tokensの和集合。古い通常visual tokensのKVはevictし、gist tokenのKVだけを残す。各フレームのvisual tokenは120個なので長期部分の圧縮率は120/8=15倍。古い履歴Nに対するcacheとattentionコストはO(NL)からO(NM)へ低下（M=8, L=120）。**総KV容量が15分の1になるわけではない**：短期・anchorの完全tokenは別途保持される。長期部分は依然Nに比例して増える。

Attention maskは現在のvideo/action tokenがanchor、recent、gistにアクセスするよう設計され、学習時も同じ可視性を再現する。gist tokenはlearnableであるため、既存モデルへの単純なtraining-free patchではない。

# Experiment Setup
RMBenchの9種類の双腕memory-dependent tasksを評価。各タスク50 expert demonstrationsで学習し、各100 rolloutで成功率を測定。3カメラ画像を384×320 mosaicに結合、14次元の双腕状態・行動を使用。video DiTは30 blocks/24 heads、action DiTも30 blocks、8 GPUsでAdamW学習。比較はπ0.5、FastWAM、LingBot-VA。実機はARX双腕＋RealSense D455、Shell GameとLook and Pressを各20回。

# Main Results
| RMBench平均成功率 | π0.5 | FastWAM | LingBot-VA | MemoryWAM |
|---|---:|---:|---:|---:|
| 9 tasks | 10.4% | 5.9% | 78.2% | **83.0%** |

タスク別ではCover Blocksが0/0/79/**98**%、Press Buttonが0/0/84/**87**%、Battery Tryが16/20/41/**41**%。つまり全タスクで大幅な改善があるわけではない。実機Shell Gameは5/20、13/20、**18/20**、Look and Pressは0/20、14/20、**15/20**（順にπ0.5、LingBot-VA、本手法）。Full-historyと比べ低latency・低GPU memoryと論文は報告するが、単一GPU上の一律ms/GBの代表値を本文から確証できないためここでは数値を記載しない。Fig.4は単一層のlatency/VRAM比較でありend-to-end値と混同しない。

# Ablation
| 設計 | Cover Blocks | Press Button | 2タスク平均 |
|---|---:|---:|---:|
| anchor除去 | 58 | 90 | 74.0 |
| gist除去 | 75 | 5 | 40.0 |
| recent window除去 | 96 | 69 | 82.5 |
| 全履歴attention | 96 | 87 | 91.5 |
| **Hybrid memory** | **98** | **87** | **92.5** |

特にPress Buttonではgist除去による性能低下が顕著。全履歴を残す場合よりハイブリッドがわずかに良いが、これだけで「全履歴が一般に有害」とは断定できない。

# Limitations
Wan系video diffusionの意味理解・推論能力の限界を継承。長期gistはフレームごとに増えるため真の固定長記憶ではない。モデル全体約6Bで追加学習を要する。RMBenchの評価は9タスクで、異なるロボット・長時間連続運用への外挿には慎重さが必要。throughput、control frequency、絶対VRAM、長期安定性の統一指標は本文から確認できた範囲に限定して解釈する。

# Taxonomy・関連研究
- `vla / model + compress / persistent video-side KV`。**直接的なTransformer KV最適化**。
- [MemoryVLA](2025-2508.19236-memoryvla.md): perceptual-cognitive memory bank。全履歴KV圧縮とは別系統。
- [MEM](2026-2603.03596-mem.md): multi-scale embodied memory。評価条件をそろえず優劣を断定しない。
- [ECHO](2026-2605.10993-echo.md): 外部の階層的経験検索・consolidation。内部KV圧縮ではない。
- [VLA-Cache](2025-2502.02175-vla-cache.md): 連続観測間のvisual token reuse。MemoryWAMは履歴保持と圧縮が中心。
