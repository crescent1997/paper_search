# Learning to Inject: Automated Prompt Injection via Reinforcement Learning

## 概要

**GCG系の最適化をjailbreakからindirect prompt injectionへ移す際に、何を目的関数にすべきか**を明確化する論文。通常のjailbreakでは「拒否しない」ことを誘発するlog-probabilityをsurrogateにできるが、agentのprompt injectionでは正しい引数を持つ特定tool callを発生させなければ成功しない。そこでbinaryの攻撃成功を直接使いながら、比較モデルから連続的な学習信号を得る。重要なのは、[Meta-SecAlign](../Defense/2025-2507.02735-meta-secalign.md)を**実測対象**として評価している点。これはInstruction Hierarchy防御のadaptive attack評価に直結する。
