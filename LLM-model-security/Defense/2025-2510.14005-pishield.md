# PIShield: Detecting Prompt Injection Attacks via Intrinsic LLM Features

## 概要

Prompt injectionをモデル応答の後から検査するのではなく、**untrusted dataに命令らしい文字列が混入していることを、LLMの中間層のactivationで検出**する。対象のbackend model自体を再学習せず、`last-token residual stream` に軽量なlogistic-regression probeを載せる。特に、instruction-tuned modelではclean/contaminatedの表現が線形分離しやすく、base modelではそうならないという比較が、model固有のinstruction recognition mechanismの理解に重要。
