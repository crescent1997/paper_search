# MemoryVLA++ — Perceptual-Cognitive Memory + Future Imagination

## 1. 概要・KV cacheとの関係

MemoryVLA++は、[MemoryVLA](2025-2508.19236-memoryvla.md)の**過去を覚えるmemory機構**に、**未来をlatent spaceで想像するworld model**を加えたVLA。現在観測・過去記憶・未来予測を統合したtokenでdiffusion action expertを条件付ける。長時間taskでは、過去に見たボタン状態や作業済み対象の記憶だけでなく、コンベア上の物体が次にどこへ移動するかの予測が必要となる。

重要な分類上の注意として、論文中のMemory Retrievalはattentionで`K,V`を作るが、これは**memory bankをattentionのkey/valueとして参照する演算**であり、Transformer層のautoregressive KV cache tensorを複数の観測フレームでそのまま再利用する技術ではない。MemoryVLA++はVLAの長期記憶アーキテクチャ研究として`KVcache/vla/`に収録する。

## 2. 問題設定・先行研究との差

通常のVLAは現在フレーム中心で、過去のsubtask完了や隠れた物体の位置など非Markov的な履歴に弱い。MemoryVLAはworking memoryとPerceptual-Cognitive Memory Bank（PCMB）を使い、履歴検索・冗長性統合を行うが、未来の動的変化は明示的に想像しない。MemoryVLA++は**SVDをmanipulation videoで適応させたworld model**からfuture latentを取り出し、pixel imageの完全生成・decodeを避けて行動に必要な予測だけを利用する。対照的に[ChainVLA](2026-2608.02326-chainvla.md)は未来画像ではなく**前回の未実行action suffix**を次のqueryに渡す。

## 3. 手法

### 3.1 Vision-Language-Cognition（VLC）とWorking Memory

現フレームからvision encoderで**perceptual tokens**（幾何・物体・空間的細部）を抽出し、LLM（7B）によるinstruction条件付き**cognitive tokens**（意味・進捗の要約）を生成する。両者をworking memoryとして、現在のactionとPCMB検索queryの両方に用いる。Perceptual/cognitiveの2 streamを分けることが重要。

### 3.2 Perceptual-Cognitive Memory Bank（PCMB）

過去のperceptual `m_i^p`、cognitive `m_i^c`をそれぞれ保存し、time embeddingをkey側へ加えて時系列順序を表す。

$$
K^x=[m_1^x+TE(t_1);\ldots;m_L^x+TE(t_L)],\quad
V^x=[m_1^x;\ldots;m_L^x],\quad x\in\{p,c\}.
$$

$$
\hat H^x=\mathrm{softmax}\left(\frac{q^x(K^x)^\top}{\sqrt{d_x}}\right)V^x.
$$

2層のattention+FFNでretrievalし、現在tokenとretrieved contextをgating fusionする。

$$
g^x=\sigma(\mathrm{MLP}([x,H^x])),\qquad
\tilde x=g^x\odot H^x+(1-g^x)\odot x.
$$

Memory bankの容量`L`を超えると、**時間的に隣接する最も類似した2 entryを平均してmerge**する。FIFOで古いentryを無条件に捨てるのではなく、冗長な近接観測をまとめて過去の重要変化を残す設計。Perceptualとcognitive streamは各々consolidationする。MemoryVLAの基本機構を継承しているため、MemoryVLA++独自の貢献と混同しない。

### 3.3 World Model-Based Imagination

**Stable Video Diffusion（SVD, 1.5B）**を基盤に、現観測とCLIPで符号化したinstructionを条件としてmanipulation動画でworld modelを適応学習する。学習時の目的はnoise付きfuture videoの復元。VLA学習時には適応済みworld modelを**freeze**する。

推論ではfuture RGB frameの完全復元・VAE decodeをせず、**partial denoising**のUNetから複数scaleの中間future latent featureを抽出する。空間・時間attentionで将来の物体運動を捉え、現在のmemory-augmented tokensをqueryとして未来latentを検索・統合する。最後に現在の知覚、過去記憶、未来想像を組み合わせたfull temporal-aware tokensを生成する。Imagination生成のdenoising stepは**1 stepでも意味のあるfuture dynamicsを表現**できると報告する。

### 3.4 Action expertと学習

Cognitive tokenが高水準のsemantic guidance、perceptual tokenが細部の視覚情報を提供し、**diffusion action expert（約300M）**が連続action chunkを生成する。Action samplingはDDIM **10 steps**、classifier-free guidance scale **1.5**。World model自体のmanipulation適応、VLA/Memoryの学習が必要であり、**training-freeなKV reuseやplug-and-play compressionではない**。

## 4. Experiment Setup

- **Simulation**: LIBERO（Spatial/Object/Goal/Long-10/Long-90）、SimplerEnv-Bridge、Mikasa-Robo、CALVIN ABC→D、LIBERO-Plus。一般操作・長期記憶・未来予測・環境変化を分けて評価。
- **Real robots**: 3種類のrobot platform、一般操作、memory-dependent、imagination-dependentのタスク群。長期タスクはsubgoalを含むstep-wise scoringで評価。
- **Training**: LLM 7B + diffusion expert 約300M、world model SVD 1.5B。8×A100またはH20、PyTorch FSDP、global batch 208–256、learning rate 2e-5。LIBEROの最初の4 suitesは60k steps、Long-90は30k steps、world modelは40k steps（benchmarkごとに設定差あり）。
- **Inference benchmark**: RTX 4090とHGX H20、bf16、single-view、action chunk 16、300 runs。**Latency/throughput/GPU memoryはTable Xで比較可能**。
- **Baselines**: 元のMemoryVLA、CogACT、pi_0、OpenVLAなど。複数baselineは出典論文からの値であり、全条件で同じtraining computeとは限らない。

## 5. Main Results

### 5.1 Simulation（Tables I–IV）

| Benchmark | MemoryVLA | MemoryVLA++ | 備考 |
|---|---:|---:|---|
| LIBERO 5-suite平均SR | 96.5% | **98.4%** | Long-90: 95.6→97.8% |
| SimplerEnv-Bridge平均SR | 71.9% | **73.9%** | CogACT 57.3%、pi_0 68.4% |
| Mikasa-Robo平均SR | 41.2% | **44.4%** | 5 temporal tasks |
| CALVIN ABC→D 平均連続task数 | 4.09 | **4.29** | CogACT 3.25、pi_0 3.92 |

LIBEROではSpatial **99.8**、Object **100.0**、Goal **98.2**、Long-10 **96.0**、Long-90 **97.8**。Mikasa-Roboの5 taskではShellGameTouch **97**、InterceptMedium **40**、RememberColor3 **50**、RememberColor5 **19**、RememberColor9 **16**。**MemoryVLA++がMemoryVLAよりすべてのmemory taskで良いわけではない**（RememberColor5: 30→19、RememberColor9: 20→16）。

### 5.2 Real-robot（Table VI）: 評価対象の違いに注意

| Task群 | 比較baseline（CogACT） | MemoryVLA | MemoryVLA++ |
|---|---:|---:|---:|
| General tasks（6種） | 76% | **85%** | **評価なし** |
| Long-horizon memory-dependent（6種） | 57% | **83%** | **評価なし** |
| Long-horizon imagination-dependent（5種） | 49% | 65% | **77%** |

論文abstractの「+9/+26/+28pp」は3 task群の改善を並べたもので、**最初の2群の85%と83%は元のMemoryVLAの結果**。MemoryVLA++の実機での追加効果が直接検証されるのは**imagination-dependent tasksの65→77%（+12pp）**であり、CogACTからは+28pp。この区別は研究比較上重要。

### 5.3 推論効率（Table X）

300 runs、bf16、single-view、chunk 16の値。

| 方法 | RTX4090 latency | RTX4090 throughput | H20 latency | H20 throughput | GPU memory |
|---|---:|---:|---:|---:|---:|
| Baseline | 0.187 s | 85.6 Hz | 0.236 s | 67.8 Hz | 15.8 GB |
| MemoryVLA | 0.194 s | 82.5 Hz | 0.246 s | 65.0 Hz | 16.6 GB |
| **MemoryVLA++** | **0.241 s** | **66.4 Hz** | **0.301 s** | **53.2 Hz** | **21.7 GB** |

RTX4090でbaseline比**+54ms（約29%遅延増）**、MemoryVLA比**+47ms（約24%遅延増）**。GPU memoryはbaseline比**+5.9GB（約37%増）**、MemoryVLA比+5.1GB。表のHzはchunk 16とlatencyから得られるaction throughput相当であり、実機closed-loop control frequencyを直接測ったものとは区別する。**長期成功率向上は計算・メモリ負担と交換**している。

### 6.2 Imagination modeling（Table VIII、定性的結論）

1 denoising stepで競争力のある成功率を示し、step増加の改善は限定的で計算負荷が増える。Future imagination horizonを長くすると長期decisionの成功率が向上する傾向。本文Table VIIIの細部数値は今回のアクセス可能なテキスト抽出で完全照合できなかったため、推測して補わない。

## 7. Limitations / 批判的評価

1. **推論効率の観点では改善ではなく悪化**：GPU memory 21.7GB、latency 0.241s。VLA KV cacheの直接削減・再利用の成果と混同しない。
2. 元のMemoryVLAのmemory ablationと、++固有のworld-model ablationを分離する必要がある。MemoryVLA++はSVDの追加学習・推論を要求し、training-freeではない。
3. Real-robotの一般/記憶依存タスクで++の数値がない。Abstractの3群を全て++の実機成績として引用するのは不正確。
4. Mikasa-Roboの一部RememberColor taskは++で悪化。未来想像が全タスクに一様に有効とはいえない。
5. Memory consolidationは最も似た隣接entryをmergeするが、重要eventの長期保持保証、memory write/forgettingの最適性は証明していない。
6. **公式コード公開状況**：著者の`shihao1895/MemoryVLA` repositoryはMemoryVLA/MemoryVLA+のコードを公開しているが、2026-10-30確認のREADMEでは**MemoryVLA++ code/weightsはTODO未完了**。そのため本論文の`code`は`null`とし、既存コードを++の実装と誤認しない。
7. PDFはweb取得時に容量上限を超えたため、arXiv公式の**HTML全文（付録含む）**を主に精読。本文の表・数式はHTMLで確認したが、図の細部とTable VIII全セルは完全な画像照合を終えていない。

## 8. Taxonomy / 関連研究

- **分類**: `KVcache/vla` / long-term memory / perceptual-cognitive memory bank / world-model imagination / diffusion action expert。
- **既登録**: [MemoryVLA](2025-2508.19236-memoryvla.md)（過去記憶のみ）、[MEM](2026-2603.03596-mem.md)（multi-scale memory）、[NativeMEM](2026-2607.06678-nativemem.md)（visual historyをaction-awareにtoken圧縮）。
- **比較**: [ChainVLA](2026-2608.02326-chainvla.md)はaction continuationを持ち越すがfuture videoを想像しない。[TempoFit](2026-2603.07647-tempofit.md)は過去frameのlayer-wise KVを直接再利用するため、メモリの種類とGPU costの論点が異なる。[OxyGen](2026-2603.14371-oxygen.md)はVLM prefill/KVのcross-task共有によるserving高速化。
- **研究課題**: PCMBのmemory tokenをKV cacheに変換・固定し、時間的位置encodingや更新の整合性を保ったままVLM prefillを削減できるか。Future imaginationのコストを選択的起動で抑えられるか。
