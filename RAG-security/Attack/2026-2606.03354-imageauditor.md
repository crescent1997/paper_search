# ImageAuditor: Membership Inference Attack against Image-based Retrieval-Augmented Generation

> text RAG向けmembership inferenceをImage-based RAG (IRAG)へ拡張するAttack。candidate imageそのものをtext queryへ挿入できないcross-modal retrieval問題と、T2Iではgenerator outputがimageになるため従来のQ&A型membership signalを使えない問題を、retrieval segment / extraction segmentの分離、Reward-Guided Policy Optimization (RGPO)、task-specific scoringで解決する。

## 概要

Image-based Retrieval-Augmented Generation (IRAG) は、外部image databaseからreference imagesをretrieveし、frozen generatorへ渡してtext-to-image (T2I) generationやvisual Q&Aを行う。

このdatabaseがweb-scrapedかつopaqueである場合、特定imageがdatabaseへ収録されているかはcopyright / privacyの観点から重要になる。ImageAuditorは、candidate imageがtarget IRAGのretrieval databaseに含まれるかをblack-box interactionから判定するmembership inference attack (MIA)を提案する。

既存text-RAG MIA、特に[Riddle Me This!](2025-2502.00306-riddle-me-this.md)や[E-MIA](2026-2605.00955-e-mia.md)では、candidate documentの内容からqueryを構成し、そのdocumentがdatabaseに存在するときだけ回答しやすい質問を作れる。しかしIRAGではcandidateがimageなので、そのpixel contentをtext queryへ直接挿入してtarget imageを強制retrieveすることができない。

ImageAuditorはこの問題を「target imageをretrieveさせること」と「retrieveされた事実をgenerator outputから検出すること」に分解する。

## 問題設定 / Threat Model

attackerはmembershipを調べたいcandidate image $x$ を既に所有している。

目的は、

```
x ∈ target IRAG retrieval database ?
```

というmembership bitを推定すること。

attackerはtarget databaseの内容を直接読めず、IRAGへ少数のtext queriesを送り、そのoutputsだけを観測する。

これはdatabase contentsそのものを復元する[CopyBreakRAG](2024-2411.14110-feedback-guided-extraction-copybreakrag.md)や[RAGCrawler](2026-2601.15678-connect-the-dots.md)とは異なり、candidate itemについてmembershipを判定するprivacy attackである。

一方でcandidate image自体を事前に持つ必要があるため、未知databaseをゼロからcrawlするattackよりattacker knowledgeは強い。

## Text-RAG MIAがIRAGへ直接移植できない理由

### 1. Cross-modal Retrieval

text RAGではcandidate passage中のrare phraseやfactsをqueryへ入れれば、そのpassageをretrieval上位へ誘導できる。

IRAGではqueryはtext、target itemはimageであるため、imageそのものをqueryへコピーできない。

高品質captionを作っても、caption embeddingとtarget image embeddingのcross-modal gapにより、large databaseからそのimageを安定してretrieveできるとは限らない。

### 2. Membership Signal Extraction

text RAGではcandidate passageに依存する質問を複数作り、generator answer correctnessやsemantic similarityをmembership signalにできる。

T2I IRAGではoutput自体がimageなので、「target passageについて質問して正答したか」というsignalが存在しない。

Visual Q&Aでも複数retrieved imagesがまとめて利用されるため、特定candidate imageの寄与が薄まる。

## 先行研究からの改善点

### Riddle Me This! / E-MIAとの関係

[Riddle Me This!](2025-2502.00306-riddle-me-this.md)はcandidate documentから自然なquestionsを作り、複数回答をaggregateしてmembershipを推定する。

[E-MIA](2026-2605.00955-e-mia.md)はcandidate document中のhard evidenceをexam-style questionsへ変換し、より明確なmember/non-member gapを作る。

両者では「candidate textをretrieveさせる」ことが比較的容易であり、主な工夫はmembership-sensitive question constructionにある。

ImageAuditorではcross-modal retrieval自体が難しいため、**retrieval queryをpolicy optimizationで学習する工程**が追加される。

## Attack Overview

各attack queryを2つのfunctionally isolated segmentsへ分ける。

```
attack query
  ├─ extraction segment
  │    └─ retrieved target imageの影響をoutputへ露出させる
  │
  └─ retrieval segment
       └─ candidate imageをretrieveさせるようRGPOでoptimization
```

この分離により、retrieval segmentは「target imageを検索結果へ入れること」だけに集中し、extraction segmentは「membership差をgenerator outputへ増幅すること」に集中できる。

## RGPO: Reward-Guided Policy Optimization

### Motivation

candidate imageからcaptionを1つ生成してqueryにするだけではcross-modal retrievalが不安定。

またtext tokensはdiscreteなので、continuous embedding gradientを直接使ったoptimizationもlocal optimumやnon-smoothnessの影響を受ける。

そこでretrieval segmentを生成するstochastic policyを用意し、candidate segmentsをsampleしてrewardに基づきpolicyを更新する。

### Reward-ranked Candidates

各candidate retrieval segmentについて、candidate imageとのcross-modal retrieval qualityをrewardとして評価する。

RGPOはabsolute reward regressionではなく、生成候補をrewardでrankし、その相対的な優劣をpolicy updateへ利用する。

これによりembedding landscape上でexplorationを維持しつつ、target imageをretrieveしやすいtext regionへpolicyを移動させる。

論文ではfinite-sample settingでexploration / exploitationをbalanceするoptimality analysisも与える。

### Query Length

retrieval segmentを長くするとtarget imageを特定する情報量は増えるが、一定長を超えると改善は飽和する。

実験では約8 tokens付近でretrieval / attack performanceがほぼ飽和し、非常に長いadversarial promptを必要としない。

## Extraction Segment

retrievalに成功しても、それだけではmembership判定できない。

ImageAuditorはtaskごとに「target imageがcontextへ入った場合にoutput distributionがどう変わるか」を分析し、promptとscoring ruleをco-designする。

## T2I Setting

T2Iではgenerator outputがimageなので、text answer correctnessは使えない。

そこでextraction segmentによってcandidate imageのvisual informationをgenerationへ反映させ、生成画像とcandidate imageを**同一modalityのimage similarity**で比較する。

memberの場合はRGPOによってcandidate imageがreferenceとしてretrieveされやすく、そのvisual characteristicsがoutputへ反映されるためscoreが高くなる。

non-memberの場合は同じqueryでもcandidate imageがcontextへ入らず、output similarityが低くなる。

重要なのは、retrievalではtext-image cross-modal similarityを扱う一方、membership scoringではimage-image similarityを使い、cross-modal noiseを避けることである。

## Visual Q&A Setting

Visual Q&Aではretrieved imagesについてfine-grained informationを回答させるextraction promptを構成する。

candidate imageがretrieveされた場合にだけ答えやすいvisual attributes / detailsをelicitationし、candidateとのalignmentやanswer signalをmembership scoreへ変換する。

複数reference imagesによるsignal dilutionを抑えるようprompt / scoringを設計する。

## Multi-query Aggregation

single queryのscoreはretrieval stochasticityやgenerator varianceの影響を受ける。

そこでcandidate imageごとに複数attack queriesを実行し、得られたmembership scoresをK-meansでclusterする。

member/non-member score distributionsのseparationを利用し、単純averageより安定したdecisionを得る。

主要実験では**4 queries per audited image**という小さなbudgetでも高いAUROCを達成する。

## Experiment Setup

論文はT2IとVisual Q&Aの複数IRAG configurationsを評価する。

### T2I Generators

- SDXL
- Stable Diffusion 1.5
- Kandinsky系model

### Visual Q&A / Multimodal Models

- Qwen2.5-VL
- LLaVA-1.6

### Datasets

- MSCOCO
- WikiArt
- Stanford Dogs
- MMQA等

異なるvisual domainsを用いて、特定datasetだけのmemorization signalではないことを検証する。

### Baselines

既存text-RAG / poisoning ideasをIRAGへadaptした、

- Naïve querying
- PoisonedRAG-style adaptation
- BadRAG-style adaptation

等と比較する。

### Metrics

中心metricはAUROC。

privacy auditing用途では低false-positive領域も重要なため、TPR@low-FPRも評価する。

## Main Results

複数のIRAG systemsにおいて、ImageAuditorは**4 queries / audited imageでAUROC 0.80超**を達成する。

低false-positive領域でも代表的settingで **TPR@5% FPRがおよそ50%**に達し、単にthreshold中央付近だけでmember/non-memberを分離しているわけではない。

target IRAGと同じretrieval embedding modelをattackerが使えず、より弱いshadow embedding modelしか利用できないsettingでもAUROCは概ね**0.75前後**を維持し、完全white-box retriever accessへの依存を緩和している。

## Ablation / Robustness

### RGPO

RGPOを使わずcaption等を直接retrieval segmentとして利用すると、cross-modal retrieval successが低下し、最終membership AUROCも悪化する。

したがってIRAGではsignal extraction以前に「candidate imageをcontextへ入れる」optimizationが主要bottleneckになる。

### Retrieval Segment Length

token数増加に伴いperformanceは改善するが、約8 tokens付近から飽和する。

これはattackが長大で不自然なpromptを必須としないことを示す。

### Extraction / Scoring Co-design

T2Iでcross-modal scoreをそのままmembership判定へ使うより、generated imageとcandidate imageを同一modalityで比較する方がdiscriminative signalが強い。

Visual Q&Aでもgeneric questionよりcandidate-specific fine-grained elicitationが有効。

### Query Aggregation

query数を増やすとvarianceが下がり、K-means aggregationによりmembership decisionが安定する。

ただしsingle-queryでもchanceを上回るsignalがあり、4-query程度でcost/performanceの良い領域に到達する。

### Retriever Mismatch

attacker側shadow retrieverとtarget retrieverが異なる場合もattackは完全には崩れず、RGPOで学んだretrieval languageに一定のtransferabilityがある。

## RAG Security Taxonomyでの位置づけ

```
RAG privacy leakage
  ├─ Content extraction / reconstruction
  │    ├─ CopyBreakRAG
  │    └─ RAGCrawler
  │
  └─ Membership inference
       ├─ Riddle Me This!        [text RAG]
       ├─ E-MIA                  [text RAG]
       └─ ImageAuditor           [image / multimodal RAG]
             ├─ RGPO retrieval optimization
             └─ task-specific signal extraction
```

ImageAuditorが漏らす中心情報はdatabase contentsそのものではなく、**attackerが既に持つcandidate imageがretrieval databaseへ含まれているか**というmembership bit。

そのためCopyBreakRAG / RAGCrawlerより漏洩情報量は小さいが、web-scraped image corpusではcopyright provenanceやprivate-image inclusionを外部から監査できるため、実用上重要なprivacy surfaceとなる。

## Limitations / 成立条件

attackerはmembershipを調べたいcandidate imageを事前に所有する必要がある。未知databaseのcontentsを直接discoverするattackではない。

target imageをtext queryからある程度retrieve可能であることも必要。cross-modal retrieverがcandidate imageをどのtext queryからもほぼsurfaceしない場合、RGPOでもmembership signalを作れない。

複数queriesを必要とするため、strict rate limitingやper-image auditing detectionはattack costを上げられる。

また本手法はIRAG固有のcross-modal retrieval / image generationを利用するため、text-only RAGへそのまま適用するものではない。

membership inferenceは「収録されている」ことを示すprivacy signalであり、retrieved imageそのもののpixel-perfect reconstructionを示すものでもない。

## 実装・研究上の示唆

text-RAG MIAではcandidate contentをqueryへ直接埋め込めるため、retrieval engineeringが見過ごされやすい。ImageAuditorはmultimodal RAGでは**retrieval誘導そのものがoptimization problemになる**ことを示している。

これは今後video / audio / multimodal knowledge basesへMIAを拡張する場合にも共通する。

Defense側ではgenerator outputだけをfilterしてもmembership signalがsemantic / visual similarityとして残る可能性があり、

- retrieval rate limiting
- query diversity monitoring
- candidate-specific repeated-query detection
- retrieval randomization
- output influence suppression

などretrievalとgenerationの両側を考える必要がある。
