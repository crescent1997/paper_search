# MrM: Black-Box Membership Inference Attacks Against Multimodal RAG Systems

> **MrM**は、画像をretrievalするmultimodal RAGに対するblack-box membership inference attack。candidate imageの重要objectを一部隠し、非公開DBから元画像がretrieveされた場合だけ、VLMの回答が隠した内容を復元できるという差を統計的に利用する。通常のtext RAG向けMIAがそのまま使えない**image input / text outputの非対称性**に対処する。

## 概要

Text-only RAGではcandidate documentの文章を一部maskしてcompletionを比較する方法や、RAG responseとcandidate documentのsemantic similarityを利用する方法が研究されてきた。しかしmultimodal RAGでは、private DBにあるのはimage–text pairsであり、external userが得られるのはVLMのtext responseだけという構成が多い。画像をそのまま問い合わせるだけでは、generatorが自身のvisual recognition能力で正答したのか、retrieved private imageを参照したのかが区別しにくい。

MrMは**retrievalを成立させつつ、query imageからは一部情報を消す**ことでこの問題を扱う。maskされた領域の内容をVLMが正しく説明できるなら、retrieved contextが情報源である可能性が上がる。さらに、mask自体を適当に選ぶとVLMの一般知識だけで容易に補完できるため、counterfactual proxy modelでinformativenessを評価する。

本論文は未知corpusを丸ごと抽出する手法ではなく、**既知のcandidate imageがprivate retrieval DBに存在するか**というmembership bitを推定する研究である。

## 問題設定 / Threat Model

- **Target**: private image DBを参照するmultimodal RAG。CLIP系retrieverとVLMを含み、画像+text queryからtext responseを返す。
- **Attacker goal**: candidate image `I` またはcandidate set `D_i={I_1,...,I_N}` がDBに含まれるかを判定する。sample-level MIAとset-level MIAを区別する。
- **Attacker access**: target imageの候補を保有し、text/image queryを繰り返し送信できる。observationsはtext responseのみ。retrieved items、DB、model weights、logits、embeddingにはaccessしない。
- **Auxiliary model**: targetとは別のcounterfactual proxy VLMを用い、candidate maskの選択に必要な情報量を見積もる。したがって**victimはblack-box**だが、攻撃者側の補助モデルを一切不要とする意味ではない。
- **Boundary**: imageのmembership推定が目的であり、image/captionの内容そのものの再構成は評価対象の中心ではない。

## 先行研究からの改善点

Text RAGのmembership inferenceは、candidate textとRAG answerの比較、masked-word prediction、自然言語queryの正答性集約などを利用する。既登録の[Riddle Me This!](2025-2502.00306-riddle-me-this.md)はdocument-specific natural interrogationを用いるが、image retrievalでは出力がtextだけなので単純なsimilarity比較が難しい。

MrMはこの**cross-modal evidence gap**に対し、maskingによるcounterfactualを導入した点が差分。retrievalを壊すほど大きな変換をかけず、VLMが自力では補完しにくいobjectを選ぶことで、member/non-memberの回答分布を分離する。

後続・関連する[ImageAuditor](2026-2606.03354-imageauditor.md)はcross-modal query optimizationとmembership aggregationを扱う。一方MrMはobject-aware perturbationとcounterfactual mask selectionが中心である。

## Method / Algorithm

### 1. Object-aware Data Perturbation

candidate image `I` に対してobject detection / segmentation model（論文ではSAM等）でsalient objectsを特定する。各object `o_j` の領域mask `M_j` を作り、元画像からそのobjectを隠したquery imageを得る。

`I_tilde_j = I ⊙ (1 - M_j)`

画像全体を強く壊すのではなく、**意味的に独立したobjectを選択的に隠す**ことが重要。maskが大きすぎるとretrieverが元画像へ到達できず、maskが弱すぎるとVLMが自力で正答できてしまう。ここにはretrieval visibilityとmembership evidenceのtrade-offがある。

### 2. Counterfact-informed Mask Selection

すべてのobject maskが同程度に有効とは限らない。たとえば「皿の上のリンゴ」は周辺contextだけから推定できるかもしれないが、画像固有の別objectは推定しにくい。

MrMは**counterfactual proxy VLM**へmask画像を与え、元objectの推定確率、top-k候補の分布、confidence gap、entropy等を用いてmaskのinformativenessを評価する。proxyが高信頼で正答できるmaskは、victim RAGもDB参照なしに正答する可能性があるため、membership discriminationには不向きとみなす。

ここでの狙いは、**retrievalに十分な視覚的手掛かりを残しながら、generatorのparametric/visual priorだけでは答えられない部分を選ぶ**ことである。

### 3. Black-box Response Observation

選択したmasked candidate imageと質問をtarget mRAGへ送信し、mask部分の意味がtext answer中で復元されるかを観測する。DB内に元画像が存在すれば、retrieved original imageが失われた視覚情報を補い得る。DBにない場合は、proxyと同様にguessingや不確実な回答が増えると期待される。

評価はtarget modelのlogitsを使わず、**text-only responseの正誤・最初に正答した試行番号**をmembership signalとして扱う。

### 4. Statistical Membership Inference

繰り返しqueryに対し、最初に正しいmasked semanticsが復元されたturn `x` を観測する。論文は幾何分布に基づくtrial modelを使い、member/non-member仮説に対する統計検定を構成する。本文ではmember側を帰無仮説として扱い、`p-value < α`（例 α=0.05）なら非memberと判定する構成が示される。

単発のYES/NO回答を信じるのではなく、**複数queryで得られる再構成挙動の分布**から判定する点が、単純なimage comparisonよりもrobustなmembership inferenceにつながる。

### 5. Set-level Membership

candidate imageが複数ある場合はsample-levelのevidenceを集約してset-level membershipを評価する。set size `K` が増えると統計的に強いsignalが得られるが、必要なquery数や対象画像数も増える。

## Experiment Setup

- **Datasets**: COCO、Flickr。各datasetから**5,000 imagesをknowledge base**に使用し、member/non-member評価用imageを各1,000件抽出する設定。
- **Victim models**: GPT-4o-mini、Gemini-2、Pixtral、Qwen-VL、GLM-4v、Moonshot、InternVL-3、Claude-3.5など8種類のcommercial / mainstream LVLM。
- **Retriever**: CLIP-based multimodal retrievalを含むRAG構成。maskしたimageが元画像をretrieveできるかと、generatorがtextで正答できるかを分けて評価する。
- **Baseline**: 従来の単純なMIA判定法（論文図ではBaseline）。MrMのobject-aware / counterfactual componentを外したablationも比較する。
- **Metrics**: sample-level / set-level ROC-AUC、低FPR条件のTPR@5%FPR、membership classification性能。set-levelでは `K=1,5,10,20` を比較。
- **Additional evaluations**: model transfer、component ablation、adaptive defenses、open-source VLMへの追加検証。

## Main Results

### Set-level ROC-AUC

論文FigureのFlickr結果から代表的な値を抜粋する（括弧内はAUC）。

| VLM | MrM K=1 | MrM K=5 | MrM K=10 | Baseline K=10 |
|---|---:|---:|---:|---:|
| Claude-3.5 | 0.84 | 0.99 | **1.00** | 0.83 |
| GLM-4v | 0.85 | 0.97 | 0.99 | 0.93 |
| InternVL-3 | 0.81 | 0.99 | **1.00** | 0.90 |

COCOでも、GPT-4o-miniではMrM K=1 **0.73**、K=5 **0.93**、K=10 **1.00**、Baseline K=10 **0.75**。Gemini-2やQwen-VL等でもKを増やすとMrMのAUCが急速に改善する。著者はK≈10でほぼ飽和するモデルが多いと報告する。

**解釈**: K=10でAUC≈1.0はcandidate setのmembership discriminationを示すものであり、1枚の画像のmembershipが常に100%当たるという意味ではない。sample-levelとset-levelの数字を混同しないことが重要。

### Cross-model Behavior

8種類のVLMで一貫してbaselineより強い傾向が報告されるが、K=1のAUCにはモデル差が残る。image recognition能力、retrieval sensitivity、text responseの保守性が異なるため、同一のmasking policyが全モデルで等価な情報量を持つわけではない。

## Ablation / Robustness / Defense Evaluation

### Object-aware Perturbationの寄与

Flickr / GPT-4o-miniのablationでは、full MrMはK=1で**0.83**、K=5で**0.95**、K=10で**1.00**。object-aware componentを除くとK=1 **0.63**、K=5 **0.79**、K=10 **0.87**に低下する。objectを意味単位でmaskすることが、単なるpixel-level obstructionより有効なmembership signalを作ることを示す。

### Counterfactual Mask Selection

proxy modelで容易に推定できるmaskを除外することで、target RAGのretrievalによる情報追加と、VLM自身の一般知識によるguessingを分離する。これはtext RAGで問題になる**parametric knowledge confounder**のimage版である。mask selectionの質はretrieval成功とgeneration discriminationの両方に影響する。

### Adaptive Defense / Open-source Transfer

論文はadaptive defenses下でも性能が維持される傾向を報告し、追加実験でLLaVA-1.5-7B、Qwen2-VL-7B-Instruct、DeepSeek-VL-7B-Chat、Llama-3.2-11B-Vision-Instructなどのopen-source modelも評価する。結果はattackが単一API固有のartifactに限られないことを示唆する。ただし個別防御の強さやmodel-specificな失敗条件はPDFの設定を踏まえて解釈すべきである。

## Limitations / 成立条件

1. **Candidate imageが既知**: private DBの画像を未知の状態から発見・複製する攻撃ではない。対象画像を持っているユーザがDB内の存在を調べるprivacy attack。
2. **Auxiliary proxyが必要**: victim内部はblack-boxでも、mask選択にはobject detectionとcounterfactual proxy VLMを使用する。完全なzero-auxiliary-data attackではない。
3. **Retrieverとgeneratorの両方に依存**: masked queryが元画像をretrieveできないとmembership signalが弱くなる。retrieval failureとgeneration failureの切り分けが必要。
4. **Dataset bias**: COCO/Flickrのobject構成とmedical scans等の高類似度画像では、適切なmaskの見つかりやすさが異なる。
5. **Set-levelの高AUC**: Kを増やした際の高い性能をsample-level attackと混同できない。実運用でのquery budget、user rate limit、candidate set availabilityに制約される。
6. **Membershipの定義**: 元画像とnear-duplicateの境界や、同一subjectの別画像がある場合のfalse positiveを慎重に評価する必要がある。

## RAG Security Taxonomyでの位置づけ

**Attack → Multimodal RAG Privacy Leakage → Image Membership Inference**。text RAGのdocument membership inferenceに対応するimage-centric手法であり、knowledge-base stealingやretrieved captionの直接exfiltrationとは異なる。既登録の[ImageAuditor](2026-2606.03354-imageauditor.md)と比較すると、MrMはobject masking / counterfactual proxyを中心にし、ImageAuditorはquery optimizationを中心にする。

## 実装上・研究上の示唆

private image DBを持つRAGでは、**VLMのtext answerが画像のmembershipを暗黙に証明する**可能性がある。単純な安全promptや直接的なcaption出力の禁止だけではmembership bitの漏洩を防げない。防御側はimage-level authorization、retrieval resultの情報流制御、同一候補への反復probing、near-duplicate policy、VLMのself-knowledgeとretrieved evidenceの分離評価を設計する必要がある。
