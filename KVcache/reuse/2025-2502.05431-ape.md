# Faster and Longer Context-Augmented Generation via Adaptive Parallel Encoding

## 概要
Adaptive Parallel Encoding (APE)は、複数retrieved contextをsequentialにprefillせず独立・parallel encodingし、そのKVをgenerationへ利用する。naive parallel encodingで崩れるattention distributionを**shared prefix、attention temperature、scaling factor**で補正し、model fine-tuningやtoken-level selective recomputationなしでsequential encodingに近い品質を狙う。

## 問題設定
contextを独立encodeすれば各chunkのprefillを並列化・事前計算できるが、各chunkは他chunkを見ずにKVを作る。そのためfull sequential promptとはattention normalizationやattention sinkの位置、representation magnitudeが異なり、単純concatenationではqualityが落ちる。

[CacheBlend](2024-2405.16444-cacheblend.md)はこの差をselected tokenの再計算でrepairする。APEは**KVを再計算するのではなくattention distribution側をcalibrateする**。

## Shared prefix
各contextを完全に独立encodeすると、それぞれの先頭tokenがattention sinkとして振る舞い、結合後にsinkが多数発生する。APEは各contextへ共通prefixを与え、parallel encoding間でanchorを揃えることでこのずれを軽減する。

## Attention temperature
parallel encodingとsequential encodingではattention probabilityのsharpnessが異なる。temperature parameterを使ってattention logits/distributionを調整し、relevant tokenへの集中度をsequential encodingへ近づける。

## Scaling factor
独立encodeした複数contextをgeneration時に統合すると、attention outputのscale/massにも差が出る。APEはscaling factorで補正し、複数contextを合わせた際のrepresentation magnitudeを安定化する。

## Selective recomputation系との差
| | APE | CacheBlend / ProphetKV / A³ |
|---|---|---|
| repair対象 | attention distribution | selected token KV |
| recomputation | 基本なし | あり |
| relevance signal | query-specific selectionなし | global/query attention等 |
| granularity | context全体のcalibration | token/chunk selection |
| fine-tuning | 不要 | 不要 |
| 目標 | parallel encodingをsequentialに近づける | cached KVをfull prefillへ近づける |

[ProphetKV](2026-2602.02579-prophetkv.md)や[A³](2025-2511.17560-a3.md)がquery relevanceでrepair budgetを集中させるのに対し、APEはquery-aware selectorを持たない。

## Experiment Setup
RAG、in-context learning、long-context generationを中心に、naive parallel encoding、sequential encoding等と比較。context lengthを伸ばした場合のquality、prefill latency、end-to-end latencyを評価する。

## Main Results
RAGではsequential encoding性能の約98%、ICLでは約93%を維持し、plain parallel encodingからそれぞれ約3.6%、7.9%改善。128K contextではprefillを最大約28×高速化し、end-to-endで最大約4.5× speedupを報告する。

## Ablation / Analysis
shared prefix、temperature、scalingを個別に除いたablationではshared prefixの寄与が特に大きく、temperature/scalingも追加改善を与える。context数や長さが増えるほどnaive parallel encodingとの差が顕在化する。

## Limitations
- full sequential prefillとのexact equivalenceではない。
- query relevanceを使わないため、task-specificに重要なtokenへcomputeを集中させる仕組みはない。
- calibration hyperparametersのmodel/task依存性がある。
- parallel execution benefitはavailable GPU parallelismやbatchingに依存。
- offline reusable cacheとして運用する場合はstorage/transfer costが別途生じる。

## KV-cache taxonomyでの位置づけ
**reuse / parallel independent context encoding / attention calibration / training-free / no selective recomputation**。
