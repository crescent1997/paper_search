# Defenses Against Prompt Attacks Learn Surface Heuristics

## 概要

**prompt-injection防御が成功率を下げても、benignな低優先度情報を適切に扱う能力を損なう可能性**を、controlled diagnosticで分析したACL 2026 Main論文。特に[StruQ](../Defense/2024-2402.06363-struq.md)と[SecAlign](../Defense/2024-2410.05451-secalign.md)をmodel-level defense baselineとして実際に評価している。既存の[SecFid](2026-2606.30783-secfid.md)と同じsecurity–utility問題を、**position/token/topicという学習されたshortcut**へ分解する点が新しい。
