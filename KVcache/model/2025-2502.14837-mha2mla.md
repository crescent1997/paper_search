# Towards Economical Inference: Enabling DeepSeek’s Multi-Head Latent Attention in Any Transformer-based LLMs

> DeepSeek系のMulti-head Latent Attention (MLA)を「新規pretraining専用architecture」にせず、既存Llama等へ移植する方法を示す研究。

## 背景

MHAでは各head分のK/Vをcacheするためmemory costが大きい。MQA / GQAはKV head数を減らすが、attention parameterization自体のcapacityも減る。

MLAはK/Vを低次元latentへjoint compressionしてcacheし、attention時に必要なrepresentationを復元することで、より強いcache reductionを狙う。

問題は、既存MHA modelをMLAへ単純変換するとparameter / RoPE構造が一致せず性能が崩れること。

## MHA2MLA

### Partial-RoPE

全Q/K dimensionへRoPEを適用すると、低rank compressionしたlatent KVへposition情報を吸収しにくい。そこでattention scoreへの寄与が比較的小さいdimensionからRoPEを外し、position-dependent部分とcompressible content部分を分離する。

### Joint SVD

pretrained K projectionとV projectionを別々に近似するのでなく、両者をjointに考えたSVD low-rank approximationでshared latent representationを初期化する。これにより元MHA parameterの情報をより多く再利用する。

### Data-efficient recovery

architecture conversion後は0.6〜1%程度のpretraining dataを使う追加学習で性能を回復する。

## Experiment Setup

Llama2-7B等のMHA modelを対象に、LongBench等のlong-context taskでqualityとKV cache sizeを評価。GQA化や単純low-rank変換との比較も行う。

## Main Results

Llama2-7BではKV cache sizeを92.19%削減しながらLongBench performance低下を約1%に抑える例を報告する。さらにKV quantization等のcompression手法とも併用可能。

## DeepSeek-V2 MLAとの関係

本論文の主目的はMLA自体の発明ではなく、**pretrained MHA → MLA conversion**。したがってtaxonomy上はmodel architecture categoryだが、実用面では既存model資産へMLAを導入するbridgeとして重要。

## Limitations

- 完全なtuning-free変換ではなく追加学習が必要。
- RoPE dimension selectionやrank設定がquality / compression trade-offへ影響する。
- conversion後はattention kernel / cache layoutもMLA対応が必要。

## KV-cache taxonomyでの位置づけ

**latent-representation cache reduction**。GQA/MQAがKV head countを減らすのに対し、MLAはK/V情報を低rank latent dimensionへ押し込む。YOCOがlayer方向を削るのに対し、MLAはrepresentation dimension方向を削る。

## 実装・研究上の示唆

model categoryは少なくとも、
1. head sharing (MQA/GQA)
2. latent compression (MLA)
3. cross-layer sharing (YOCO等)
に分けて見ると整理しやすい。将来的にはmodel配下をこの3 subcategoryへ分ける価値がある。
