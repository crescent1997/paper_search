# 概要
同一に見える観測でも操作の進捗に応じて次のactionが変化する。ActMem-VLAは過去の実行actionを記憶し、既存のflow matching policyに小規模なexpertを追加する。

## 問題設定・先行研究との差
MemoryVLAは観測履歴を記憶・検索するが、本手法は実行履歴を主な進捗情報にする。VLMおよび既存Action Expert (AE) を固定し、記憶による粗い行動決定と既存policyによる精細な制御を分ける。

## 手法
Mamba-2が実行済みaction blockと前回のrecurrent stateを処理して記憶表現を生成する。記憶表現をhistory K/Vに射影し、現在観測のVLM prefix KVとともにPreAction Expert (PAE) の条件にする。PAEは既存AEの選択層から初期化する。通常設定はMamba 2層、幅1024、PAE 4層。10-step denoisingの初期4 stepをPAEで、残り6 stepを凍結AEで処理し、途中のaction状態をノイズ再初期化なしで渡す。flow matching損失を用いてMambaとPAEだけを共同学習する。実行されなかった予測actionではなく実行履歴を条件にする点が重要。

## Experiment Setup
LIBERO-Mem 10タスク、8基のH100を使用した学習・simulation。各方式で訓練seed 3、評価seed 3、各20試行で1タスク180試行。実機4タスクは方式ごと各20試行。比較対象はπ₀.₅とMemoryVLA（simulation）。実機はπ₀.₅との比較。

## Main Results
|方式|LIBERO-Mem平均成功率 (%)|
|---|---:|
|MemoryVLA|49.5|
|π₀.₅|65.2|
|ActMem-VLA|80.8|

実機は28/80から51/80へ改善（35.0→63.75%、28.75ポイント増）。追加parameterは3.45%。これは実測GPU memory削減率やlatency改善率ではない。推論latency・制御周波数の定量値は未確認。

## Ablation
|設定|T6|T7|T8|平均 (%)|
|---|---:|---:|---:|---:|
|記憶なし|38.3|33.3|50.0|40.6|
|PAEなし|58.3|38.3|63.3|53.3|
|提案|80.0|40.0|45.0|55.0|

引継ぎ位置0.3/0.5/0.6で平均48.3/45.0/47.2%、標準0.4で55.0%。Mamba 4層43.3%、幅1536で55.6%、PAE 2層43.9%。ablationは1訓練seedのため総合評価と条件が異なる。T8では記憶なしやPAEなしが良く、全タスクに一様な改善があるわけではない。

## Limitations
外界の変化や実行失敗はaction履歴だけでは完全に観測できない。実機の3回ボタン押しは35%、3回ボウル戻しは55%で、反復回数の記憶は未解決。固定状態への圧縮でどの程度過去情報が失われるか、エピソードを長くした場合の頑健性は要検証。追加学習が必要。

## taxonomy
recurrent execution memory + history-conditioned flow matching。history KVを生成するが、過去Transformer KV tensorのフレーム間再利用とは異なる。MEM等との比較では保持形式、入力履歴の種類、記憶依存ベンチマーク、学習条件を揃える必要がある。
