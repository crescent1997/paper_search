# Knowledge Poisoning Attacks on Medical Multi-Modal Retrieval-Augmented Generation

> Medical multimodal RAGの画像retrievalと曖昧な医療テキストを組み合わせるquery-agnostic knowledge poisoning。

## 概要

Medical multimodal RAGの画像retrievalと曖昧な医療テキストを組み合わせるquery-agnostic knowledge poisoning。 RAGのretrieval corpusを通じて生成回答のintegrityが侵害されるリスクを扱う。private corpus extractionではなくknowledge poisoningのカテゴリに属する。

## 問題設定 / Threat Model

攻撃者はretrievalに影響する外部コンテンツを操作できることを前提とする。RAGのgenerator内部を直接変更するのではなく、retrieved evidenceの選択または解釈を通じた回答操作を検証する。論文ごとのquery knowledgeとwhite-box accessの違いは、以下の手法で区別する。

## Method / Algorithm

画像側のimperceptible perturbationでretrieval visibilityを高め、対応するtextに医学的にもっともらしいcovert misinformationを配置する。明示的な誤情報をgeneratorが自己修正する問題を、医学的曖昧性の利用で回避する設計。

## 先行研究からの改善点

[PoisonedRAG](2024-2402.07867-poisonedrag.md)のtext poisoningからmedical multimodal・unknown-query設定へ拡張。

## Experiment Setup

IU-XRay、MIMIC-CXR、CRC100k、MHIST、PCamを対象に、5種類のLVLMとCLIP / BGE-VL / SigLIP系retrieverを比較。queryを事前に知らない条件、black-box transferabilityを重視する。

## Main Results

論文はblack-box設定でもwhite-boxに近いretrieval hijackingを報告する。詳細なASR等の個別数値は本記録では未転記。

## Ablation / Transferability / Robustness

異なるmultimodal retrieverとLVLMの構成、およびblack-box transferabilityを検証。retrievalとgenerationの双方が攻撃成立に必要。

## Limitations / 成立条件

retrieval corpusへのpoisoned contentの混入可能性が必要であり、アクセス制御や信頼済みcorpusのみの運用ではthreat modelが異なる。特定のcorpus、retriever、generatorの結果を全RAGへ一般化できない。実際のpoison exposureと最終的なgeneration manipulationは別指標として評価する必要がある。

## RAG Security Taxonomyでの位置づけ

Attack → Retrieval / Knowledge Poisoning → Answer Integrity。retrieved documentの機密情報を抜き取るextraction attackとは異なり、retrievalされた証拠を汚染するintegrity riskである。

## 実装上・研究上の示唆

retrieverのranking robustnessだけでなく、retrieved passagesの出所、cross-modal consistency、generatorがevidenceをどう採用するかを分離して検証する必要がある。query-awareな防御だけでなく、未知queryへの汎化とadaptive attackerを含めた評価が重要となる。
