# Defense Against Prompt Injection Attack by Leveraging Attack Techniques

## 概要

**攻撃者が『前の指示を忘れさせる』ために使う手法を、defenderが『正規instructionへ戻す』ために反転利用する**。Ignore、Escape、Fake Completion、Fake Completion with Templateの4種類を提示し、特に会話templateを使う方法が複数モデル・複数攻撃で強い。ACL 2025 Mainへの公式採択によりvenue fallbackを満たす。

本手法は**モデルの重みを更新しないtraining-free/test-time defense**であり、LLMがsystem/developer/user/toolのprivilegeを内部的に保証する方式ではない。入力形式と末尾位置によるinstruction-followingの競合を利用する比較研究として採用。StruQ/SecAlign/ISE/Meta SecAlignと同一カテゴリの「学習済みpriority mechanism」とみなさない。
