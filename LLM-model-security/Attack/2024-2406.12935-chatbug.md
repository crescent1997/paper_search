# ChatBug: A Common Vulnerability of Aligned LLMs Induced by Chat Templates

## 概要

Chat templateは`user`/`assistant`などのroleとターン境界をtoken列へserializeし、instruction tuning時の出力分布を強く条件づける。本研究は、**training時の定型formatから逸脱したpromptを与えると、モデルが本来の安全なassistant応答分布から外れる**というChatBugを指摘する。単なる有害要求の言い換えではなく、role boundary・assistant prefillという**model側のinstruction-following mechanism**に依存する攻撃として収録する。AAAI 2025公式採択、arXiv 2406.12935と題名・著者を照合済み。

注意：中心実験は**safety jailbreak**であり、system > user > toolの優先順位を厳密に比較するInstruction Hierarchy専用実験ではない。ChatInjectやPrompt Injection as Role Confusionの**技術的先行研究**として重要だが、StruQ/SecAlign突破を実証したものではない。
