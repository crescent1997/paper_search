# Localize and Neutralize: Gradient-guided Token Suppression against Visual Prompt Injection Attack

> **検証状況: REVIEW（正式アップロード対象外）**。arXivの著者・ID・初投稿日、ICML/PMLR正式採択、abstractとcode URLを一次情報で確認。PMLR PDFがoctet-streamとして取得できず、詳細表・付録・証明の前提を照合できていない。引用数未確認だがICML venue fallbackは成立。

## 概要

マルチモーダルLLMに対し、画像中に隠された命令が視覚tokenを通じて言語出力へ影響する。GTMは入力画像全体を除去するのでなく、攻撃に寄与する少数のvisual tokenを同定して無効化する。**モデルの中間表現に直接介入する**という点で、prompt前処理型の検出器や外部guardrailとは異なる。既存の[CachePrune](2025-2504.21228-cacheprune.md)と比較し、攻撃寄与tokenの選択とマスクを使うが、対象がKV componentではなく視覚tokenである。

## 問題設定 / Threat Model

攻撃者は画像入力の一部または全体を操作できる。画像に潜ませた低信頼のinstructionをモデルが上位のsystem/user taskより優先することが失敗条件。論文はvisual prompt injectionおよびmultimodal jailbreakを評価する。防御者はopen-weight MLLMのhidden stateとgradientへアクセスできる推論実行環境を想定する。closed APIの利用者がそのまま適用できる方式ではない。

## 先行研究からの改善点

画像全体を一様に弱めるとutilityを落とす一方、通常のoutput probability attributionでは**次token予測が変わらない攻撃**を見逃す。GTMは生成に影響するhidden-state側の勾配を使い、攻撃を成立させるvisual tokenを識別する。入力をすべて遮断する方法と異なり、正常な画像理解に必要なtokenを残すことを狙う。

## Method / Algorithm

1. 入力画像をvision encoder / projector経由でvisual tokenに変換し、言語モデルに投入する。
2. **Hidden-State Gradient Norm (HSGN)** によって各visual tokenの出力への寄与を測る。第一生成tokenの確率に基づく単純な寄与指標は、攻撃がそのtokenを保持する場合に不適切になりうる。
3. HSGNの大きいvisual tokenを攻撃経路に重要とみなし、選択的にmask（ゼロ化）する。
4. 残りのtokenから通常の応答生成を続ける。

原論文はHSGNの順位がfull adversarial-loss gradientの順位と整合する理論結果を主張する。ただし**定理の仮定・等価性の範囲・mask比率の実装詳細はPDF本文照合待ち**。一度のforward-backward passで選択とmaskが可能とされるが、backwardの実行コストはゼロではない。

## Experiment Setup

公式abstractによる評価対象はvisual prompt injectionとmultimodal jailbreak。対象モデル・画像解像度・visual token数・攻撃方式・データセット別母数・mask比率はPDF未確認。防御側にgradientが必要なため、API-only deploymentでは直接の比較が難しい。

## Main Results

公式PMLR abstractでは、ASRを**near zero**へ低減し、model utilityを維持しつつ追加計算量を小さく抑えたと報告。**具体的なASR/utility数値は原PDFの表を未照合のため掲載しない**。研究の核は、重要visual tokenの少数性とhidden-state gradient attributionの理論的妥当性。

## Generalization / Robustness / Adaptive Evaluation

visual injectionとmultimodal jailbreakの双方を評価することは公式に確認できる。適応的攻撃者がHSGN maskingを知った上で再最適化するwhite-box adaptive attack、異なるvision encoderへの転用、複数画像・長文との複合攻撃、他モダリティへの一般化は公式abstractからは確認できず、**未検証扱い**とする。

## Limitations

- visual input特化であり、text-onlyのsystem/developer/user/tool conflictを直接解決しない。
- hidden stateとgradientが必要。vLLM等の高速推論でbackwardを挿入する際は専用の処理経路が必要。
- 画像の重要tokenを削除すると細粒度視覚理解の性能低下が起こりうる。
- 実験表・定理・appendixの精査が未完了。

## LLM Model Security taxonomy

`Defense / Model-internal Inference-time Intervention / Multimodal Prompt-Data Separation / Gradient-based Token Attribution`。Instruction Hierarchyの学習方式というより、**低信頼画像tokenの影響を推論時に遮断**する補助防御。

## 実装・研究上の示唆

[CachePrune](2025-2504.21228-cacheprune.md)のKV component maskと比較し、同じinputに対して重要token集合、mask率、ASR、task utility、追加forward/backward数、TTFTを揃えて評価するとよい。モデル内部にgradient経路が必要な点はFlashInfer/vLLMの純粋なdecode pathとは別の実装課題。画像tokenをmaskした後のKVキャッシュをどこまで再利用できるかは、本論文で確認した結果ではなく今後の研究課題。
