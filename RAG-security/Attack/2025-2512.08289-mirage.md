# MIRAGE: Misleading Retrieval-Augmented Generation via Black-box and Query-agnostic Poisoning Attacks

> strict black-boxかつquery-agnosticなcorpus poisoningを扱うmulti-stage framework。

## 概要

strict black-boxかつquery-agnosticなcorpus poisoningを扱うmulti-stage framework。 RAGのretrieval corpusを通じて生成回答のintegrityが侵害されるリスクを扱う。private corpus extractionではなくknowledge poisoningのカテゴリに属する。

## 問題設定 / Threat Model

攻撃者はretrievalに影響する外部コンテンツを操作できることを前提とする。RAGのgenerator内部を直接変更するのではなく、retrieved evidenceの選択または解釈を通じた回答操作を検証する。論文ごとのquery knowledgeとwhite-box accessの違いは、以下の手法で区別する。

## Method / Algorithm

Persona-driven query synthesisで未知user query distributionを近似し、semantic anchoringで潜在query intentに対するretrieval visibilityを確保し、adversarial Test-Time Preference Optimization (TPO)でpoisoned passageの説得力を高める。surrogate feedbackにより直接victim model内部へ依存しない。

## 先行研究からの改善点

[PoisonedRAG](2024-2402.07867-poisonedrag.md)に比べ、target queryの事前知識とwhite-box accessを要求しない方向へthreat modelを緩和。

## Experiment Setup

3種類のlong-form domain-specific datasetsに基づく新benchmarkを構築。retriever/LLMの組合せを変えたtransferability、stealthiness、attack effectivenessをbaselineと比較。

## Main Results

論文は既存baselineに対するattack efficacyとstealthinessの改善、および異なるretriever-LLM構成間でのtransferabilityを報告。正確な個別数値は未転記。

## Ablation / Transferability / Robustness

query distributionの未知性とsurrogate modelへの依存を評価。retrieval visibilityと生成時のpersuasivenessを別の役割として扱う。

## Limitations / 成立条件

retrieval corpusへのpoisoned contentの混入可能性が必要であり、アクセス制御や信頼済みcorpusのみの運用ではthreat modelが異なる。特定のcorpus、retriever、generatorの結果を全RAGへ一般化できない。実際のpoison exposureと最終的なgeneration manipulationは別指標として評価する必要がある。

## RAG Security Taxonomyでの位置づけ

Attack → Retrieval / Knowledge Poisoning → Answer Integrity。retrieved documentの機密情報を抜き取るextraction attackとは異なり、retrievalされた証拠を汚染するintegrity riskである。

## 実装上・研究上の示唆

retrieverのranking robustnessだけでなく、retrieved passagesの出所、cross-modal consistency、generatorがevidenceをどう採用するかを分離して検証する必要がある。query-awareな防御だけでなく、未知queryへの汎化とadaptive attackerを含めた評価が重要となる。
