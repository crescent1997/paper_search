# The Gate, Not the Cache

## 概要・問題設定
Visual tokenをskipする際、部分計算から次の選択gateを作ると重要な変化を見落とし続ける場合がある。

## 手法・先行研究との差
ロボットがaction chunkを実行している間にdense forwardを実行し、新しいattention情報とKVを次の制御に使うactuation-slack refreshを提案する。

## Experiment Setup / Main Results
LIBERO-Objectで90%のtokenをskipすると、通常のKV reuseは成功率68%、token pruningは31%。Clean gateを用いた提案方式では両者98%。Serve latencyは123.3msから97.0msへ短縮した。

## Ablation / Limitations
Gate生成元とKV baseを切り分けて検証する。総計算量はFull inferenceの約1.6倍、電力は約18%増加するため、GPU計算節約ではなくaction実行との並列化によるlatency改善である。
