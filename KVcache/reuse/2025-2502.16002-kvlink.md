# KVLink: Accelerating Large Language Models via Efficient KV Cache Reuse

## 概要
KVLinkはdocumentごとにKV cacheを独立prefillして保存し、RAG inference時にretrieved documentsのcacheを連結してprefillを省く。独立encodingしたKVを単純に並べると、position mismatchとcross-document attention欠落が起きるため、**position adjustment + trainable link tokens + mixed-data fine-tuning**でmodel自体をreuse-friendlyにする。

## 問題設定
同じdocumentが複数queryでretrievalされても通常は毎回prefillされる。document KVをoffline計算すれば再利用できるが、document単独で計算した位置と最終prompt中のglobal positionが異なる。またdoc2を単独prefillした時にはdoc1が存在しないため、doc2 KVにはdoc1→doc2のcross-context interactionが入っていない。

positionだけ直しても後者は回復しない。

## Position adjustment
cached KVを最終promptへ配置するとき、特にRoPEを含むpositional encodingをglobal positionに合わせて調整する。これにより独立prefill時のlocal positionをそのまま使うnaive concatenationのposition mismatchを解消する。

ただし**re-RoPEだけではmissing cross-attentionは戻らない**ことがKVLinkの重要な出発点。

## Trainable link tokens
各document境界へspecial link tokensを挿入し、fine-tuningによって独立encodingされたdocument間の情報をlink token経由で接続できるよう学習する。

```text
cached doc1 KV
   ↓
link tokens
   ↓
cached doc2 KV
   ↓
link tokens
   ↓
query
```

runtimeで多数のdocument tokenを再計算する[CacheBlend](2024-2405.16444-cacheblend.md)とは異なり、missing interactionへの対処をtrainingへ移す。

## Mixed-data fine-tuning
RAG QAだけに特化するとbase model capabilityを損なう可能性があるため、RAG、multi-turn conversation、summarization、instruction following、pretraining-style data等を混ぜてfine-tuningする。reuse能力と一般能力の両立を狙う。

## CacheBlend / Block-Attentionとの差
| | CacheBlend | Block-Attention | KVLink |
|---|---|---|---|
| repair | runtime recomputation | block-aware model adaptation | link tokens |
| position | cached KVを調整 | block-wise position handling | global positionへadjust |
| fine-tuning | 不要 | 必要 | 必要 |
| runtime extra compute | selected tokens | 小 | link token中心 |
| 目標 | full-prefill近似 | block reuse適応 | reusable independent docs |

[Block-Attention](2024-2409.15355-block-attention.md)と同じreuse-aware fine-tuning系だが、KVLinkはdocument境界の情報伝達をspecial link tokenへ明示的に集約する。

## Experiment Setup
7つのQA datasetsでindependent document KV reuseを評価し、standard full inferenceや既存cache-reuse法とaccuracy / TTFTで比較。さらにKV cache compressionとの併用も評価する。

## Main Results
既存SOTA reuse法に対してQA accuracyを平均約4ポイント改善。standard inferenceと比べTTFTを最大約96%削減する。precomputed KVのstorage/loading overheadに対してはKV compressionを併用してもbaselineより高いqualityを維持できることを示す。

## Ablation / Analysis
position adjustmentだけでは十分でなく、link tokensとfine-tuningを追加することでqualityが回復する。mixed-data trainingはreuse taskだけに偏ることによるgeneral capability degradationを抑える。link token設計はruntime recomputation量を増やさずdocument interactionを補うための鍵。

## Runtime上の意味
offline document prefillを最大限reuseできるため、同じcorpusが繰り返しretrievalされるRAGでTTFT benefitが大きい。一方、model weights自体をfine-tuneするため既存checkpointへそのまま適用できるtraining-free方式ではない。

またfull-size KVをstorageからloadするI/Oが新しいbottleneckになり得るため、compressionやprefetchとの組合せが重要。

## Limitations
- model-specific fine-tuningが必要。
- corpus/model更新時にはcache再生成が必要。
- link tokenで全pairwise cross-document attentionを厳密再現するわけではない。
- arbitrary base modelへtraining-freeに導入できない。
- cache storage / transfer overheadが残る。

## KV-cache taxonomyでの位置づけ
**reuse / independent document cache / position correction / reuse-aware fine-tuning / link-token fusion**。

KVLinkは「独立doc KV + re-RoPEだけでは一致しない」という問題に対し、runtime selective recomputationではなく**learned linking**を選んだ重要な別系統。
