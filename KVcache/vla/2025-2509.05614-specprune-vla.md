# 概要
連続する観測の重要tokenの共通性を利用し、action単位とlayer単位の二段階で計算を削減する。追加学習不要。

## 問題設定・先行研究との差
現在のattentionだけに基づくpruningでは後段の重要性を見落とす可能性がある。VLA-Cacheのような過去KVの直接再利用ではなく、過去の重要度を選択の手掛かりとする。

## 手法
- Action-level static pruning: 前回の深層attentionと現在の画像変化・浅層attentionを組み合わせる。連続観測で重要領域が共通するという仮定を利用する。
- Layer-level dynamic pruning: attention entropyに応じた層ごとの重み付けと重要度の更新で段階的にtokenを削減する。
- Action-aware controller: 手先速度に応じて粗い移動と精密操作を区別し、削減の強さを変える。精密操作では情報を多く残す。
過去のattentionを保持することと、過去のK/V tensorを利用してprojectionを省略することは区別が必要。

## Experiment Setup
OpenVLA-OFT、DB-OFT、CogACTを対象にLIBERO、SimplerEnv、実機で検証。FastV、DivPrune、SparseVLM、VLA-Cache、EfficientVLAと比較。以下の詳細値は前回のv3本文調査に基づく。

## Main Results
| LIBERO | 成功率 (%) | 高速化倍率 | 残存FLOPs (%) |
|---|---:|---:|---:|
| OpenVLA-OFT | 96.6 | 1.00 | 100 |
| FastV | 93.3 | 1.44 | 57 |
| DivPrune | 89.4 | 1.46 | 54 |
| SparseVLM | 95.6 | 1.28 | 77 |
| VLA-Cache | 96.9 | 1.07 | 83 |
| EfficientVLA | 88.9 | 1.52 | 35 |
| SpecPrune-VLA | 96.1 | 1.46 | 43 |

実機latency 187.7→110.2 ms。RTX 3090でLLM部分2.09倍、E2E 1.57倍を報告。FLOPs削減率と実測時間の改善率は異なる。GPU memory、物理制御周波数の定量値は未再確認。

## Ablation
過去のglobal attentionなしの場合、token recall 92→84%、成功率96.1→93.4%。Entropy-based weightingを単純平均に置換するとrecall 88→66%、成功率96.1→92.0%。各recall値は異なるablation条件のため直接比較しない。

## Limitations
観測の急変や遮蔽で過去の重要度が陳腐化する可能性がある。手先速度は操作難易度の完全な指標ではない。長時間運用での頑健性は未確認。TRIAGEとの統合は研究上の仮説であり、実験による裏付けはない。

## taxonomy
Training-free temporal / layer-wise visual token pruning。Transformer KVの直接再利用ではない。
