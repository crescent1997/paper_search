# 概要
AURA-Memはfrozen VLA backboneから得た観測表現を固定サイズのfast-weight stateへ書き込むかを、次の行動に対する予測誤差（action surprise）で判定する。重要な変化がないstepではstateを更新しない。狙いは単純なtoken容量削減ではなく、edge環境でのmemory write traffic削減である。

# 問題設定・先行研究との差
KV cacheは時間とともに増大するが、AURAのstateは次元を固定してO(1)の保持量とする。H2O/SnapKV/VLA-CacheなどのKV evictionと違い、過去KV tensorを選んで残す方式ではない。reconstruction目的で学習する記憶とも異なり、write gateをaction-prediction errorに結び付ける。

# 手法
- Frozen OpenVLA-OFT backboneのhidden representationをprojectionしてlatent z_tを得る。
- 固定サイズのfast-weight state W（行列と補助ベクトル）を持つ。
- gate確率p_tが閾値τを超えたときだけ更新し、そうでなければstateを保持。
- state readoutを次actionの条件付けに使用。write budget/rate knobで制御周期に合わせた書込頻度を調整。
- stateサイズの例: d_k=d_v=32, fp32, batch 1で(32×32+32)×4 = **4,224 bytes**。これはモデル全体のGPU memoryではない。

# Experiment Setup
- 合成sequential recall / sparse recall課題、T=96/128等、複数seedとbudget設定で評価。
- 比較: always-write/fixed-size-state、random/periodic write schedule、KV armなど。
- arXiv abstractにはLIBERO-Long（OpenVLA-OFT 7B、各arm 60 episodes）評価の記述があるが、本文Section 7 item 9およびAppendix C model cardは「all results are on synthetic benchmarks; no real-robot validation」と記載する。**この不整合が解消するまでLIBERO結果を検証済み実験として扱わない**。

# Main Results
- 合成タスクではbest O(1) baselineとほぼ同じaccuracyを保ちながら、書込回数を約5.19–6.13倍削減。条件により最大9.19倍だが、ほぼaccuracy飽和した条件である。
- 長さ100,000 stepの推論stateは4,224 bytesで一定。GPU allocator peakは別指標で約43.1 MB（対象構成の測定値）であり、4,224 bytesと混同しない。
- abstractにはLIBERO-Long success 0.233（AURAとbase）、0.217（always-write KV）、write 7倍削減との記述。ただし本文の明示的なsynthetic-only制約と矛盾するため**保留値**。
- Wall-clock latency、J/step、実機制御周波数、end-to-end throughputの実証は確認できない。

# 主要ablation
- 同write budgetのrandom/periodic schedulingではaction-error gateのwrite efficiencyを再現できないと報告。
- 合成SparseRecallTaskではevent stepとdistractor stepでgate activationが異なり、重要イベントを選択する傾向。
- write-rateの下限をイベント密度より低くするとaccuracyが急落する。gateは無条件に低書込化できるわけではない。
- gradient-active parametersはscheduled-write比較群より41.9%多いとの開示があり、学習コストは同条件ではない。

# Limitations / 検証上の注意
1. **論文内の整合性問題**: abstractのLIBERO-Long評価とSection 7 item 9/Appendix Cのsynthetic-only宣言が衝突する。原著者の訂正・再現資料なしに実機やLIBERO成功率を確定的に引用しない。
2. O(1)は推論stateだけ。trainingはBPTTでO(T) memory。
3. 最良O(1) baselineに対するaccuracyの優位性は主張されず、主な利点は書込削減。
4. 9.19倍は飽和した容易な条件での最大値。wall-clock / energy / device寿命への効果は未実測。
5. checkpointと論文の主要sweepでstate次元が異なる（checkpointは64、sweep代表は32）。
6. 定量比較の多くはsynthetic benchmarkで、長期manipulation成功率への外挿はできない。

# Taxonomy / KV cacheとの関係
`KVcache/vla/` / **action-gated recurrent fast-weight memory**。KV eviction/compressionではなく、固定サイズの別記憶。MEMとの違いは、自然言語での長期記憶ではなく、action-errorに応じた書込頻度制御に焦点を当てる点。
