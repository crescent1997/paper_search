# Learning When to Act or Refuse: Guarding Agentic Reasoning Models for Safe Multi-Step Tool Use

## 概要

MOSAICは、**安全判断をagent modelのaction policyの一部として学習**させるpost-training。推論を `plan → optional safety check → act / refuse / answer` と構造化し、tool observationを受け取るたびに、次のactionの危険性を判断できるようにする。単なるprompt-injection detectorでもexternal sanitizerでもない。一方で、**system/developer/user/toolのrole orderingを直接学習するInstruction Hierarchy手法ではなく**、tool-using agentのexecution safetyを扱う隣接研究である。
