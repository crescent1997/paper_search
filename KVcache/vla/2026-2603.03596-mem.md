# ★ MEM — Multi-Scale Embodied Memory

## 概要・問題設定
長時間のロボット操作では、観測履歴をそのままVLMに入力すると視覚token数と推論負荷が増える。MEMは短期と長期で異なる記憶表現を使う。

## 手法と先行研究との差
短期記憶は動画、長期記憶は言語要約として保持する。動画エンコーダに時間方向のcausal attentionを導入し、履歴を現在の視覚表現へ集約する。過去フレームを単純連結する方式と異なり、下流VLMの入力token数を抑える。KV cacheを直接再利用する方式ではない。

## Experiment Setup / Main Results
最大約15分の長時間タスクと、失敗後に行動戦略を変更する能力を評価。長期タスクのtask progressとin-context adaptationを主な指標とする。定量的な比較値の詳細は原論文を参照。

## Ablation / Limitations
言語記憶と動画記憶の役割を分けて評価する。履歴入力の圧縮とKV cache容量の削減は同義ではなく、時間方向attention自体の計算コストも考慮が必要。GPU memory・control frequencyの厳密な比較値はこの簡易版では省略した。
