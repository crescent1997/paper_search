# L2 Norm-Based KV Cache Compression

## 概要・問題設定

H2O、SnapKV等のattention-based KV evictionは重要tokenを選ぶためにattention scoreを使う。しかし、**FlashAttentionのようなfused attention kernelでは全attention mapを外へmaterializeしない**ため、score取得のためのkernel変更や追加計算が必要になる。

本論文はKey embedding自体の`L2 norm`に注目し、**normが小さいKeyほど高いattentionを得やすい**という経験的な相関を報告する。これに基づき、cacheがbudgetを超えたら**normが大きいKeyと対応するValueをevict**する。モデル変更・fine-tuning・attention map取得は不要で、保存KV token数を削減する`compress`に属する。

## 手法と観察

### 1. Low-norm Keyとattention sink

著者らはLlama 2/3やGemmaでattention mapとKey normを可視化し、BOS、句読点など**高いattentionを集めるtokenのKey normが小さい**傾向を観測した（Fig. 2）。これは「大きいKey normほどattentionが高い」という直感とは逆に見えるが、softmaxのattentionはQueryとの**方向・内積**に依存し、normだけでは決まらない。

著者らは、low-norm Keyが少数の特徴次元に強いactivationを持ち、共通のsink方向にQueryが揃う可能性を示唆する。特定次元をzero化するとattention mapが変わる一方、ランダムな次元のzero化では同じ変化が起きない（Fig. 6–7）。**原因の完全な理論説明はなく、経験的proxy**として利用している。

### 2. Selection rule

各layer/headのKey `k_{l,h,i}` に対して `s_i = ||k_{l,h,i}||_2` を計算する。budgetを超えたら**大きい`||k||_2`から削除**し、低norm側のKeyと対応するValueを保持する。

- Token重要度の算出に現在のQueryも将来のQueryも不要（**query-independent**）。
- Attention probability tensorを保持する必要がないため、FlashAttentionとの統合が比較的容易。
- Fig. 1で一部head/layerは相関が弱い。論文の標準設定では**最初の2 layerを圧縮しない**。したがって、全layer一律の無条件な50%削減ではない。
- 計算量はKey norm計算と上位/下位の選別に依存する。cache容量削減は示すが、**実装込みend-to-end decode throughputの大規模benchmarkは主結果ではない**。

### 3. Attention Loss Ratio (ALR)

削除したKVに対応するattention massの和を`L_{l,h}^m`と定義し、**将来のattention scoreを知っていた場合の理想的なeviction**との差 `Y_{l,h}^m` を計算する。異なる削除数`m`にわたって和を取った`ALR`を使い、layer/headごとのlow-norm heuristicの適合度を評価（Eq. 1–3）。ALRが大きいheadはnormだけでのselectionが不利で、**head適応budget**の余地がある。

## Experiment Setup

- Backbone：Llama 2-7B、Llama 3-8B、Gemma、Llama 2-7B-80K、Llama 3.1-8B等。論文Limitationsでは**最大8B規模**と明記。
- Language modeling：Wikipedia（追加でcode dataset）上のperplexity/next-token accuracy。
- Long-context：Needle-in-a-Haystack、Passkey Retrieval、LongBenchのNarrativeQA/Qasper/HotpotQA/2WikiMQA/QMSum等。
- Baseline：Full KV、low-norm保持、**high-norm保持**、random eviction、[FastGen](2023-2310.01801-fastgen.md)の一部policy。
- 重要な比較条件：FastGen比較はFlashAttentionに合わせ、**attention scoreを必要とするFastGen policyを除外**し、local/special/punctuation policyのみを利用（§3）。FastGenの全機能との同条件比較ではない。

## Main Results

1. **Language modeling**：Wikipedia上のLlama 2-7B / Llama 3-8B / Gemmaで、KV tokenを約**50%削減**してもperplexityの悪化は小さい（Fig. 3）。Low-norm保持はrandom保持・high-norm保持より明確に優れる。
2. **Needle-in-a-Haystack**：Llama-2-7B-80KでKVを**50%削減して99% accuracy**を報告（Fig. 4a）。本文には30%削減では元の性能を維持したとも記載。
3. **Passkey Retrieval**：同モデルで**90% KV削減でも100% accuracy**を報告（Fig. 4b）。これは合成retrieval taskの結果であり、一般的なmulti-hop reasoningの品質保証ではない。
4. **LongBench**：Llama 3.1-8Bの複数subsetで、50%削減でも比較的小さい精度低下。一方、high-norm保持は著しく悪化（Fig. 4c）。
5. **Kernel compatibility**：attention mapを必要としないためFlashAttentionとの併用に向く。ただし**実測の大規模end-to-end speedupを示した論文ではなく**、memory削減と品質を主張の中心として読むべき。

## 主要ablation・分析

- **Low vs high vs random**：high-norm Keyだけを残すとNeedle/Passkeyでほぼ0まで精度が落ちる条件があり、low-norm側に重要情報が集中するという観察を裏付ける。
- **Layer selection**：最初の2 layerや一部中間layerではALRが高く、normとattentionの相関が弱い。これらを圧縮対象から除外する実験をAppendixで実施。
- **Key次元の介入**：low-norm Keyのpeaked activationをzero化するとattention分布が大きく変わるが、ランダム次元では変わりにくい（Fig. 7）。
- **FastGen比較**：attentionを使わないFastGen policyに限定した場合、L2 norm selectionがperplexityで優位。**full FastGenとの包括的な比較とは解釈しない**。

## Limitations

- **最大8B程度のモデルのみ**。大規模GQA/MLA、Qwen系、reasoningモデルで同じlow-norm相関が成り立つか未検証。
- Key normがattention重要度のproxyになる**理論的理由は未解明**。RoPE前後のnormは回転の性質上不変でも、Queryとの方向関係は変化するため、normだけではattentionの順位を決められない。
- Head/layerによって相関が異なり、特定headでは重要tokenを誤削除する可能性がある。Uniform budgetよりhead適応が有効かは将来課題。
- Future Queryを使わない利点の裏返しとして、**質問固有のretrieval relevanceは評価しない**。KV reuse時のfull-prefill approximationやRAG fusionを目的にしていない。
- Norm計算・Top-K・不連続なindex管理のruntime overheadと、実際のserving kernelでのthroughputは別途検証が必要。

## Taxonomy / 技術的系譜

`compress > training-free token eviction > key-statistic / attention-free selection`。

- [H2O](2023-2306.14048-h2o.md)、[SnapKV](2024-2404.14469-snapkv.md)：Query由来のattentionを集計して重要tokenを決定。本手法は**Keyのみ**で決定。
- [FastGen](2023-2310.01801-fastgen.md)：head別のpolicy選択と対照的に、単一のKey norm指標を用いる。
- [HeadKV](2024-2410.19258-headkv.md)、[Ada-KV](2024-2407.11550-adakv.md)：headごとのbudget配分に関心。本論文のALR観測は、**low-norm指標もheadごとに信頼度が違う**ことを示唆。
- [LAVa](2025-2509.09754-lava.md)：attention × Value normからhead横断の重要度を定義する。Key norm単独の本手法とは**使用する信号と最適化対象が異なる**。
- [ProphetKV](../reuse/2026-2602.02579-prophetkv.md) / [A³](../reuse/2025-2511.17560-a3.md)：質問に関連するtokenを選んで再計算・fusionするreuse手法。本手法は質問非依存の**保存KV eviction**。
