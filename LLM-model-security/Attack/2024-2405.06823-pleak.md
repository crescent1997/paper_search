# PLeak: Prompt Leaking Attacks against Large Language Model Applications

## 概要

LLMアプリケーションの非公開system promptの機密性を評価する研究。モデルへの入力と応答から、上位権限に置かれた指示がどの程度漏えいするかを分析する。
